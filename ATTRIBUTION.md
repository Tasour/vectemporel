# Attributions

## Données historiques importées

- **Chronas** — https://chronas.org — données historiques (géométries provinciales, données annuelles de dirigeants/cultures/religions/capitales, marqueurs), licence **CC BY-SA 4.0**. Code de l'API sous **MIT** (`Chronasorg/chronas-api`).
- **Wikipédia / Wikidata** — https://www.wikipedia.org — source dérivée des données Chronas, licence **CC BY-SA**.
- **OpenHistoricalMap** — https://www.openhistoricalmap.org — données cartographiques historiques, licence **ODbL**.
- **Natural Earth** — https://www.naturalearthdata.com — domaine public (contours de référence utilisés par l'atlas local).

## Bibliothèques de rendu

- **Three.js r180** — https://threejs.org — Copyright 2010-2025 Three.js Authors, licence **MIT** (`SPDX-License-Identifier: MIT`). Bundle local tree-shaké `public/three-bundle.js` généré depuis `scripts/three-entry.js`, utilisé pour la sphère WebGL. Aucune autre bibliothèque tierce n'est chargée au runtime.

## Inspiration fonctionnelle (aucun code copié)

- **Histography** — https://histography.io — Matan Stauber, Bezalel Academy (2015). Interaction timeline « un point = un événement », échelles multiples, catégories, « Feeling Lucky ». Projet fermé : **reconstruction originale uniquement**.
- **pilgrims-path** — https://github.com/beneisenberg/pilgrims-path — CC0-1.0. Répétition espacée Leitner, rappel actif, entrelacement, double codage, feedback immédiat.
- **ultimate-history** — https://github.com/omarkohl/ultimate-history — MIT (code) / CC BY-SA 4.0 (contenu). Histoire comme graphe d'événements et de personnes.
- **Tempora** — https://github.com/Mofferato/tempora — MIT. Simulation mondiale sur 12 000 ans, PWA hors ligne.

Consulté le 2026-11-21. Les projets fermés ne fournissent aucun code ; seuls les principes d'interaction sont décrits et réimplémentés de façon originale.
