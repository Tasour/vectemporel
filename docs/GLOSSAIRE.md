# Glossaire

- **Épic** — événement catalogué par Chronas (guerre, invention, personne), associé à une année.
- **Rupture** — année où au moins 20 provinces changent de souverain dans les données Chronas. Voir ADR-0012.
- **Anomalie** — changement de capitale sans changement de souverain ; extrait brut, pas une validation.
- **Souverain** — code du dirigeant ou de l'État (`ruler`) d'une province pour une année donnée.
- **Culture** — code de la culture dominante d'une province (`culture`) dans Chronas.
- **Province** — unité géographique historique de Chronas, distincte des pays modernes.
- **Contour** — géométrie vectorielle d'une province sur le globe.
- **Chunk** — fichier local regroupant les données d'un siècle (41 chunks de -2000 à 2000).
- **Extrait** — affirmation recalculable depuis les données mais non validée historiquement.
- **Validé** — point accepté avec signature ; aucun point de l'application n'est actuellement « validé ».
- **Leitner** — méthode de répétition espacée à cinq boîtes (intervalles 1, 3, 7, 16, 35 jours).
- **Streamgraph** — graphique de composition dans le temps ; ici la part de population estimée par famille.
- **Deep link** — URL contenant l'état de l'application (`?year=`, `?trail=`, `?turn=`, `?histomap=`, `?compare=`…).
- **Territoire** — ensemble des provinces partageant le même souverain à une année donnée.
- **Terminateur** — ici une ombre stylisée dépendant de l'année, sans prétention astronomique.
- **Budget** — nombre de requêtes et volume transféré à la première visite.
