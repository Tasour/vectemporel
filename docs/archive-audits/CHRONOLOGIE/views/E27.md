# E27 — Transitions

| Champ | Valeur |
| --- | --- |
| Lentille | E27 (module `src/views/chronology/E27.js`, point d'entrée `E027.js`) |
| Vue | CHRONOLOGIE — `src/views/chronology.js` |
| Thème | Moments de bascule : ère → ère, repère → repère, filtre, entrée de vue |
| Chantiers | E27-01 … E27-10 — **10 / 10 implémentés** |
| Contrat | `register('E27', ctx => {...})` depuis `./registry.js` |
| Style | `ctx.css('chronology-e27', …)` — une seule feuille, injectée une fois |
| Validation | `node --check` ✓ — zéro `console`, zéro réseau, zéro `Math.random()` |

## Contrat et périmètre

La lentille ne modifie ni le store ni le rendu de `chronology.js` : elle
n'ajoute que des éléments dérivés du DOM déjà produit. `ctx` fournit
`{ viewId, stage, layout, css, el, reducedMotion() }`. Tout est rejoué à chaque
rendu complet ; les éléments sont donc protégés par un test d'idempotence
(`getElementById` / `querySelector`) avant création. La région live est créée
hors de `#app` pour survivre au `innerHTML` de la coque.

## Les dix chantiers

### E27-01 — Ruban de transitions d'ères
Jonctions écrites en texte réel entre ères consécutives, dans `#e27-era-seams`
(`« ère A → ère B · ère B → ère C »`). Information indexable, aucun `aria-hidden`.

### E27-02 — Marqueur de seuil de l'ère active
Étiquette textuelle « en cours » (`.e27-active-mark`) dans la bande portant
`aria-current="true"`. Le franchissement n'est jamais porté par la seule
couleur.

### E27-03 — Annonce live de transition d'ère
Région `#e27-transition-live` (`role="status"`, `aria-live="polite"`), unique
par document. Annonce uniquement lors d'un changement effectif, avec une clé
`pays:ère` pour ne pas confondre deux ères de même identifiant dans deux pays.

### E27-04 — Fil de transition entre repères
`#e27-stepper` dans la fiche latérale : `précédent → courant → suivant`, avec
les titres et les années. Les bornes de liste sont explicites (« début de
liste », « fin de liste ») plutôt que silencieuses.

### E27-05 — Mesure de portée
`#e27-ecart` : écart en années entre le repère courant et le précédent,
recalculé depuis `data-year`. Grandeur chiffrée dérivée des données, pas d'une
constante.

### E27-06 — Témoin de transition de filtre
`#e27-filtre-temoins` : quand une recherche ou un thème est actif, le texte
précise que la lecture quitte le périmètre d'une ère pour parcourir tous les
repères du pays, avec le nombre affiché.

### E27-07 — Pont clavier entre ères
`#e27-pont-eres` : boutons « ← Ère précédente » / « Ère suivante → », 36 px
minimum, focus visible, `aria-controls` et `disabled` aux bornes. Ils
déclenchent exactement la même transition que les bandes d'ère.

### E27-08 — Transition d'entrée de vue
`#e27-note-entree` dans le bloc de situation : rappel que la chronologie
s'ouvre depuis la carte du monde et que « Retour au monde » rétablit la vue
globale.

### E27-09 — Synthèse chiffrée de l'ère franchie
`#e27-metriques-ere` : nombre de repères affichés et plage `début → fin` avec
durée en années, recalculés depuis `data-start` / `data-end` de la bande active.

### E27-10 — Régime de mouvement réduit
Animation de pulsation unique, placée sous `@media (prefers-reduced-motion:
no-preference)` et neutralisée par `@media (prefers-reduced-motion: reduce)`
et par l'attribut `data-e27-motion="reduit"` posé quand `ctx.reducedMotion()`
est vrai. Aucune autre règle n'est touchée.

## Cadrage technique

- Identifiants tous préfixés `e27-`, uniques dans le document ; classes
  confinées au préfixe `.e27-*` (hors `#e27-*`).
- Cible DOM vérifiée avant chaque insertion : la lentille reste sans effet si
  un élément source est absent, sans lever d'erreur.
- Zéro appel réseau, zéro `console.*`, zéro `url(...)` / `@import`, zéro
  `Math.random()` ; `node --check` validé sur `E27.js` et `E027.js`.
- Le cache des modules ES garantit un seul `register('E27')` même si
  `index.js` charge à la fois `E027.js` et `E27.js`.
