# E053 — Contraste du focus et de la tabulation (seconde passe)

Lentille V2 de la vue Constellation. Un seul appel `register('E053', ctx => …)`
(ligne 127), une garde `ctx.layout` avant tout ajout au DOM (lignes 129–130),
une unique feuille `constellation-v2-e053` (ligne 9, corps 12–94, posée ligne
140). Les dix chantiers sont **inédits** : ils ne reprennent ni l'anneau à double
contraste, ni le ratio à couleurs fixes, ni la pastille, ni la légende, ni la
région live, ni le contraste forcé, ni l'ordre documenté de la passe 1. Chaque
effet est enveloppé dans `safe()` (lignes 96–98) et ne dépend d'aucun service
externe, aléa ou minuteur.

## E053-01 — Anneau à contraste garanti par différence de couleurs

- **Preuve** — CSS lignes 13–24 : `.v2e053-blend:focus-visible::after` dessine
  un liseré blanc de 3 px (`inset: -5px`, `border-radius: 8px`) en
  `mix-blend-mode: difference`, `pointer-events: none`, `z-index: 7`. Lignes
  149–162 : la classe est posée sur chaque cible ; si sa position calculée est
  `static` (lignes 155–159), une `position: relative` inline est ajoutée avec
  `data-v2e053-pos="relative"` pour ancrer le pseudo-élément. Attribut
  `data-v2e053-blend="difference"` en ligne 151.
- **Solution** — Le liseré blanc en mode « différence » affiche le complément
  exact du fond réel, sans table de couleurs. Seules les cibles statiques
  basculent en position relative : les soleils déjà positionnés gardent leur
  géométrie. Le pseudo-élément ne capte aucun pointeur.
- **Impact** — Focus visible sur fond clair comme sombre, y compris sur une
  arête ; l'information ne tient pas à la teinte mais à l'épaisseur, au décalage
  et au rayon.
- **Effort** — Moyen : règle CSS courte, mais ancrage conditionnel à vérifier.
- **Vérification** — Tab sur un soleil puis une lune : liseré inversé visible
  dans les deux cas ; `data-v2e053-pos` absent du soleil, présent sur une cible
  de flux.

## E053-02 — Simulateur de daltonisme local et mémorisé

- **Preuve** — CSS lignes 26–28 : `.v2e053-cvd .constellation-field {
  filter: grayscale(1); }`. Lignes 164–191 : lecture de la clé `__v2e053_cvd`
  (constante ligne 10), `classList.toggle` ligne 171, bouton `#v2e053-cvd`
  « Simuler le daltonisme » (177–180), `aria-pressed` synchronisé (180–189),
  état réécrit ligne 183. CSS lignes 81–89 : cible ≥ 36 px et focus à 3 px.
- **Solution** — Bascule indépendante (donc `aria-pressed` légitime) qui
  désature seulement le champ, sans toucher au thème. L'état survit au re-rendu
  via la clé `window` préfixée `v2e053` ; un bouton existant est resynchronisé
  plutôt que dupliqué (188–190).
- **Impact** — Vérification en un clic que l'anneau, le fil de suivi et les
  marqueurs restent compréhensibles en niveaux de gris.
- **Effort** — Faible : un filtre, un bouton, une clé.
- **Vérification** — Cliquer : scène désaturée, `aria-pressed="true"`,
  `data-v2e053-cvd="grayscale"` ; re-cliquer restaure tout.

## E053-03 — Contraste réel de l'étiquette mesuré sur le fond calculé

- **Preuve** — Lignes 100–125 : `luminance()` (formule WCAG
  `0,2126 R + 0,7152 V + 0,0722 B`, seuil `0,03928`), `contrastRatio()`
  (`(clair + 0,05)/(sombre + 0,05)`), `rgbToHex()` pour les couleurs calculées.
  Lignes 193–210 : fond lu sur le champ (199, repli `#0e1116`), couleur de
  chaque cible lue en 202, ratio arrondi posé dans `data-v2e053-label-ratio`
  (205), classe `v2e053-faible` sous 4,5 (206), pire ratio dans
  `data-v2e053-label-min` (209). CSS ligne 32 : anneau porté à 4 px si faible.
- **Solution** — Mesure sur les couleurs **calculées** par le navigateur, et non
  plus sur deux constantes : le résultat déclenche un renforcement de l'anneau
  et alimente le chantier 10.
- **Impact** — Contraste auditable et réactif au thème réel ; seuil AA explicite
  dans le code.
- **Effort** — Élevé : trois fonctions pures, lectures de styles, gestion du
  pire cas, sans mesure asynchrone.
- **Vérification** — `data-v2e053-label-min` est un nombre à deux décimales,
  cohérent avec les ratios par cible ; une étiquette pâle sur fond clair fait
  apparaître `v2e053-faible`.

## E053-04 — Anneau proportionné à la taille de la cible

- **Preuve** — CSS lignes 34–38 : `outline-offset: var(--v2e053-offset, 3px)`.
  Lignes 212–222 : `offsetWidth`/`offsetHeight` (215–216), seuil « compacte »
  si une dimension < 28 px ou aire < 900 px² (217), `data-v2e053-size` (218),
  variable à `5px` ou `3px` (219), décompte dans `data-v2e053-sized` (221).
- **Solution** — Mesure unique au rendu : décalage 5 px pour les petites cibles,
  3 px pour les grandes, sans recalcul au focus.
- **Impact** — Lunes et retour gardent un anneau dégagé ; les soleils un anneau
  resserré.
- **Effort** — Faible : deux lectures, un seuil, une variable.
- **Vérification** — Une lune porte `data-v2e053-size="compacte"` (5 px), un
  soleil `"large"` (3 px).

## E053-05 — Fil de suivi des cinq dernières cibles focalisées

- **Preuve** — CSS lignes 40–44 (`.v2e053-trail`, 9 px, chiffres tabulaires).
  Lignes 224–252 : création idempotente de `#v2e053-trail` (226–231), tableau
  local (232), écouteur `focusin` délégué sur `field || layout` (237),
  `lastTarget` (242), déduplication (244–247), plafond cinq via `shift()` (246),
  texte joint par « › » (248–249).
- **Solution** — Historique textuel en mémoire locale, alimenté uniquement par
  de vrais `focusin`, sans minuteur ; la file est bornée et l'écriture
  conditionnée au changement.
- **Impact** — Le parcours récent devient visible, utile pour repérer un saut
  de focus ; `lastTarget` sert au chantier 10.
- **Effort** — Moyen : un écouteur délégué, une file bornée, un rendu conditionné.
- **Vérification** — Après trois tabs : « Parcours : … › … › … » ; le
  quatrième décale la plus ancienne entrée ; un second rendu ne duplique pas le
  paragraphe.

## E053-06 — Alerte sur les cibles masquées mais tabulables

- **Preuve** — CSS lignes 46–52 (`.v2e053-note`, bordure dorée, fond de surface).
  Lignes 254–285 : détection par `display`, `visibility`, `aria-hidden` ou
  `offsetParent === null` (262–264), `data-v2e053-hidden="true"` (267), compte
  publié (272), note « Attention : N cible(s) masquée(s) restent atteignables au
  clavier. » (280–281), retrait si compte nul (282–284).
- **Solution** — Détecte le piège du bouton invisible mais focusable, le nomme
  en texte clair et l'expose pour un contrôle automatisé ; la note est créée,
  mise à jour ou supprimée de façon idempotente.
- **Impact** — Défaut visible au lieu d'un focus inexplicable.
- **Effort** — Moyen : quatre critères, note conditionnelle, nettoyage.
- **Vérification** — `display: none` sur une planète : `data-v2e053-hidden="1"`
  et note visible ; restaurer : note retirée, attribut à `0`.

## E053-07 — Marquage des extrémités de la séquence

- **Preuve** — CSS lignes 54–56 : `.v2e053-debut`/`.v2e053-fin` en
  `:focus-visible` portent `outline-offset: 7px`. Lignes 287–310 : retrait des
  classes (289), cas vide (290–293), marqueurs `data-v2e053-extremite="debut"`
  / `"fin"` (294–299), paragraphe `#v2e053-extremes` créé une fois (300–305),
  texte « Premier arrêt : … · Dernier arrêt : … » (308).
- **Solution** — Pas de liste dupliquée : seules les bornes sont nommées et
  distinguées par un décalage d'anneau plus large ; les classes sont nettoyées
  puis reposées à chaque rendu.
- **Impact** — Orientation immédiate dans le parcours, par un indice
  géométrique et non par une nuance.
- **Effort** — Faible : deux marqueurs, une phrase, nettoyage explicite.
- **Vérification** — Premier et dernier boutons portent `debut` et `fin` ; au
  focus, leur anneau est plus éloigné que celui d'une cible intermédiaire.

## E053-08 — Repli CSS pour la préférence de contraste renforcé

- **Preuve** — CSS lignes 58–66 : `@media (prefers-contrast: more)` porte
  l'anneau à 4 px, ajoute `box-shadow: 0 0 0 3px #000` et épaissit les bordures
  de `.v2e053-note`/`.v2e053-trail`. Lignes 312–316 : attributs
  `data-v2e053-contrast-rule` et `data-v2e053-contrast-source` documentent la
  règle.
- **Solution** — Cas distinct du `forced-colors` de la passe 1. Comportement
  entièrement en CSS : aucune sonde `matchMedia`, aucun écouteur de média, aucun
  minuteur.
- **Impact** — Anneau plus épais et encadrés plus marqués pour les personnes
  ayant demandé plus de contraste, sans re-rendu.
- **Effort** — Très faible : un bloc média et deux attributs.
- **Vérification** — Activer « Plus de contraste » : anneau 4 px avec liseré
  noir ; désactiver : retour à l'état initial.

## E053-09 — Repère global de zone active au focus

- **Preuve** — CSS lignes 68–78 : `.v2e053-zone { position: relative; }`,
  `:focus-within` ajoute `outline: 2px dashed var(--gold)` et
  `outline-offset: 3px` ; le badge `.v2e053-zone-badge` passe de `opacity: 0`
  à `1` sous `:focus-within`. Lignes 318–329 : classe posée sur le champ, badge
  textuel « Zone active : constellation » créé une fois (322–327),
  `data-v2e053-zone="active"`, ou `"absente"` si le champ manque (320).
- **Solution** — `:focus-within` met en évidence le conteneur, sans écouteur ni
  surveillance du DOM ; le badge est un texte réel, pas une couleur.
- **Impact** — Portée du focus explicite : on sait que l'on est dans la
  constellation ; indices visibles même en niveaux de gris.
- **Effort** — Faible : une classe, un badge, trois règles.
- **Vérification** — Tab dans le champ : cadre pointillé et libellé
  apparaissent ; Tab suivant les fait disparaître.

## E053-10 — Annonce à la demande de la dernière cible visitée

- **Preuve** — CSS lignes 80–93 : boutons à `min-height: 36px`, focus à 3 px,
  `.v2e053-sr` masque la région live sans la retirer de l'arbre
  d'accessibilité. Lignes 331–363 : `#v2e053-where-live` avec `role="status"`,
  `aria-live="polite"`, `aria-atomic="true"` (333–340), bouton
  `#v2e053-where` « Dernière cible visitée » (342–346), lecture de
  `lastTarget` (347), messages français (349–357), écriture conditionnée
  (358).
- **Solution** — Complète les annonces automatiques de la passe 1 par une
  interrogation différée : restitue la cible, son contraste (chantier 03) et sa
  taille (chantier 04). Réutilise `lastTarget` du chantier 05, donc ne vole pas
  le focus et ne dépend pas de `document.activeElement`.
- **Impact** — État des lieux obtenu après coup, sans refaire le parcours ;
  cible ≥ 36 px et contour de focus conformes.
- **Effort** — Moyen : un bouton, une région live, deux variantes de message.
- **Vérification** — Tab sur une lune puis clic : « Dernière cible : … ·
  contraste d'étiquette … pour 1 · cible compacte. » ; avant tout tab, message
  « aucune cible visitée ».
