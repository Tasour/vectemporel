# E057 — F. Sémantique & données — silences de la matrice traités comme données

Lentille E057 — domaine F : sémantique & données. Fichier possédé : `src/views/points/E057.js` uniquement. La vue (`src/views/points.js`), le store, les filtres, le détail, `styles.css` et la coque ne sont ni édités ni doublés : E057 lit le DOM réel produit par la vue et y ajoute une portée CSS et quelques nœuds sémantiques, sans détruire le contenu existant.

Règle appliquée (`POINT_METHODOLOGY.md`, règle 7) : « Les silences sont des données : `aucune source` doit être explicite, jamais un vide masqué. » Dans la vue, une cellule `.points-cell` sans classe `has-points` affiche « · » : c'est un silence (ère × domaine sans point validé). E057 le rend lisible, étiqueté, compté et documenté au lieu de le laisser passer pour un vide. Contrat exploité : `viewId`, `stage`, `layout`, `css`, `el`, `reducedMotion` ; aucune dépendance vers le store, les filtres ni le détail. Zéro réseau, zéro aléa, zéro timer, zéro rAF, zéro `console.*`. CSS injecté par `ctx.css('points-e057', …)`.

## E057-01 — Portée CSS unique et ancrage non destructif

- **Preuve** : `E057.js:23-25` pose les invariants (un seul CSS, un seul encart, un seul résumé, une seule légende) ; `:28-33` déclare des identifiants préfixés `points-e057-` ; `:39-91` contient l'unique feuille ; `:123-126` filtre le contexte (`viewId` / `layout` / `css` / `el`) ; `:128-131` appelle `css(CSS_ID, CSS)` (cssOnce), ajoute la classe `points-e057` et le signal `layout.dataset.e057`.
- **Solution** : l'injection passe exclusivement par `ctx.css`, donc `cssOnce` garantit une seule feuille. La classe de portée est posée sur `.points-layout` et toutes les règles en sont préfixées : aucun sélecteur ne fuite hors de la vue. La garde tolère un `ctx` partiel (pas de `viewId`, pas de `stage`) sans lever d'erreur.
- **Impact** : la lentille reste inactive sur une autre vue et ne casse pas un rendu même si le registre fournit un contexte minimal ; aucune feuille dupliquée après navigation.
- **Effort** : S
- **Vérification** : relecture — une seule occurrence de `css(CSS_ID, CSS)` (`:129`), tous les IDs préfixés (`:28-33`) ; `node --check src/views/points/E057.js` PASS.

## E057-02 — Marquage structurel des cellules vides comme silences

- **Preuve** : le commentaire `E057.js:15-17` définit le silence ; `:39-46` oppose `.points-cell.is-silence` (bordure `dashed`) à `.points-cell.has-points` (bordure `solid`) ; `:150-163` compte chaque cellule et, pour celles sans `has-points`, écrit `data-silence="1"`, `data-e057State="silence"` et la classe `is-silence` ; `:192` expose `layout.dataset.e057Silences`.
- **Solution** : le vide « · » devient un état nommé et marqué dans le DOM, distinct d'une cellule renseignée. La distinction passe par la forme (pointillé) et la structure (attributs), jamais par la seule couleur ; le signal global `e057Silences` rend le total auditable.
- **Impact** : un silence ne peut plus être confondu avec une cellule normale, y compris sous `forced-colors` (`:80-87`) ; le comptage est dérivable sans lire le store.
- **Effort** : M
- **Vérification** : relecture de la branche `has-points` (`:153-157`) et du marquage (`:161-163`) ; harnais — toute cellule sans `has-points` porte `data-silence="1"` et `class` contient `is-silence`.

## E057-03 — Étiquettes sémantiques dérivées du DOM

- **Preuve** : `describeSilence()` (`E057.js:116-121`) compose la phrase ; le domaine est lu dans l'en-tête de colonne (`:136-137`, `domainNames`) et l'ère dans le premier enfant de la ligne (`:146-147`, `:152`) via `textOf()` (`:98-100`) ; `:165-175` ajoute la phrase à `aria-label` et `title` sans écraser un libellé existant, avec garde anti-doublon (`:169`, `:173`).
- **Solution** : aucune date ni aucun chiffre n'est codé en dur : ère et domaine proviennent de la grille réelle. L'ajout est non destructif (concaténation) et idempotent (test `includes`) afin de coexister avec E003 (titre + aria) et E045 (cellules étiquetées).
- **Impact** : un lecteur d'écran entend « Silence de la matrice : aucun point validé pour « Ère » × « Domaine »… » au lieu d'un « · » muet ; les libellés suivent le jeu de données sans retouche du code.
- **Effort** : M
- **Vérification** : relecture — absence de millésime ou de total littéral dans le module (hors commentaires) ; faire varier ères/domaines : les libellés changent seuls ; second passage sur le même DOM : aucune duplication (`:169`, `:173`).

## E057-04 — Encart « un silence est une donnée »

- **Preuve** : `E057.js:55-61` stylise l'encart ; `:194-203` crée un `<p id="points-e057-note">` statique, inséré avant `.points-filters`, dont le texte énonce la règle 7 (« vide justifié » / « omission justifiée ») ; `scopedNode()` (`:102-111`) garantit l'unicité.
- **Solution** : un seul nœud visible, en texte réel dans un paragraphe (donc indexable), hors région live et non modal. L'id est unique et préfixé ; un nœud périmé issu d'un rendu précédent est retiré avant réinsertion.
- **Impact** : la règle méthodologique est portée par la vue elle-même ; le silence est explicité même pour qui ne lit pas la méthodologie, sans dépendre d'une infobulle ou d'un JS additionnel.
- **Effort** : S
- **Vérification** : relecture — un seul `#points-e057-note` ; rendu → navigation → rendu : un seul encart ; le texte est présent dans le `<p>` et non dans un attribut ou du contenu CSS généré.

## E057-05 — Description associée par `aria-describedby`

- **Solution** : chaque cellule de silence est décrite par l'encart sans écraser les identifiants posés par d'autres lentilles (E009 infobulle, E045, etc.). Aucune région live n'est ajoutée : E057 est purement descriptif.
- **Impact** : l'explication rejoint le contrôle au bon endroit pour les technologies d'assistance, sans bavardage sonore ni modale.
- **Effort** : S

## E057-06 — Résumé chiffré entièrement dérivé du DOM

- **Preuve** : `E057.js:140-143` initialise les compteurs ; `:150-156` incrémente `total` et `filled` ; `:159` incrémente `silences` ; `:213-223` calcule `coverage = Math.round(filled / total * 100)` et écrit « Silences de la matrice : N cellule(s) vide(s) sur M (P avec points, couverture X %) » dans `<p id="points-e057-summary">`, inséré après `.points-title`.
- **Solution** : total = nombre de cellules, remplis = cellules `has-points`, silences = le reste, couverture = formule explicite. Aucun nombre n'est littéral : tout est recompté à chaque rendu depuis la grille.
- **Impact** : le chiffre est falsifiable par recomptage manuel de la matrice et évolue quand le dataset change ; il ne promet pas une couverture de points qu'E057 ne peut pas mesurer.
- **Effort** : M
- **Vérification** : relecture — aucun total codé en dur ; faire varier le nombre de cellules : le résumé change sans modifier le code ; contrôle de la formule `filled / total` sur un harnais à N cellules dont K vides.

## E057-07 — Légende des trois états de cellule

- **Preuve** : `E057.js:67-72` stylise la légende ; `:225-244` construit `<ul id="points-e057-legend">` avec trois entrées `■ / · / ◇` et leur texte (`:230-239`) ; les glyphes sont `aria-hidden="true"` (`:236-237`) car le texte porte le sens.
- **Solution** : trois états explicités — cellule avec points, silence, omission justifiée — avec formes et libellés ; jamais la couleur seule. L'insertion se fait après la grille, avec garde d'unicité via `scopedNode`.
- **Impact** : la nuance entre « silence » et « omission justifiée » devient lisible, y compris en couleurs forcées ; la légende reste comprise sans les glyphes pour les lecteurs d'écran.
- **Effort** : S
- **Vérification** : relecture — trois `<li>` avec texte, `aria-hidden` sur les trois glyphes, un seul `#points-e057-legend` ; capture en `forced-colors` : les trois états restent distinguables par le texte.

## E057-08 — Le silence comme grandeur mesurable par ère

- **Impact** : le silence devient comparable d'une ère à l'autre ; l'état est auditable via `data-silences` et stable après un second passage (garde du badge).

## Statut d'implémentation

Les dix chantiers E057-01 à E057-10 sont implémentés dans `src/views/points/E057.js` uniquement. CSS injecté via `ctx.css('points-e057', …)`. Aucune donnée inventée (tout est dérivé du DOM de la matrice), aucun fichier partagé touché, aucun appel réseau, aucun aléa, aucun timer ni rAF.

## Blocages / limites inter-domaines

- E057 ne peut pas décider si tel silence est une « omission justifiée » avec ID d'omission : le DOM produit par `points.js` n'expose ni `dataset` ni attribut portant cet ID. La légende distingue conceptuellement les trois états (E057-07) mais n'étiquette pas chaque silence comme omission justifiée ; cette décision revient à E056 et au store, fichiers non possédés.
- Le taux affiché en E057-06 est un taux de **cellules** (ère × domaine), pas un taux de **points**. La vue ne fournit que des compteurs par cellule : la couverture binaire 100 % et l'éventuelle comparaison à une référence relèvent de E060.
- L'`aria-label` posé sur chaque `.points-era` (E057-08) écrase le nom accessible natif du bouton (texte + badge). Le texte visuel reste intact ; une lentille qui dépendrait du nom accessible brut de l'ère devra composer avec E057.
- Aucune région live n'est ajoutée : E057 est purement descriptif. Les annonces de filtrage et de changement de périmètre restent à E019 / E041, fichiers non possédés.
