# E007 (V2) — Laboratoire de lecture matricielle et d’indice quintile

Seconde passe du domaine A (matrice & grille). Fichier possédé : `src/views/points/v2/E007.js` uniquement. La passe 1 (`src/views/points/E007.js`), la vue (`src/views/points.js`), la coque, les registres, les index et toutes les autres lentilles ne sont ni édités ni doublés. Le module est enregistré une seule fois via `register('E007', ctx => { … })` et n’injecte qu’une feuille CSS, par `ctx.css('points-v2-e007', …)`. Contrat exploité : `viewId` (`'pointsv2'`, repli `'points'`), `stage`, `layout`, `css(id, rules)`, `el(tag, cls, text)`, `reducedMotion()`. Il lit le DOM réellement produit par `points.js` — `.points-layout`, `.points-matrix`, `.points-grid`, `.points-grid-row.is-head`, `.points-filters` — et recalcule toute grandeur affichée depuis `grid.scrollWidth`, `grid.clientWidth`, `grid.scrollLeft` et `offsetLeft`/`offsetWidth` des cellules d’en-tête. Zéro réseau, zéro aléa, zéro `console.*`, zéro `innerHTML`, zéro timer, zéro rAF, zéro écouteur global. Tout DOM statique est créé par `ctx.el`.

## E007-01 — Greffon V2 ciblé, dégradable et sans dépendance

- **Preuve 1** : `E007.js:518` contient l’unique `register('E007', (ctx) => { … })`, avec un `try/catch` silencieux (`:519-524`) qui neutralise une lentille défaillante sans interrompre le rendu.

- **Preuve 3** : `E007.js:468-475` vérifie la présence de `css`, `el`, du document, de `.points-grid`, de `.points-matrix` et d’un en-tête conforme (`:475-476`) avant toute écriture ; aucun import hors `./registry.js` (`:1`).
- **Solution** : garde d’entrée en cascade et repli silencieux, sans toucher au store, aux filtres, au détail ni à une autre lentille. Le module reste un complément non destructif du rendu de base.
- **Impact** : la V2 ne peut pas casser la vue si la structure change ; elle n’ajoute aucun couplage inter-domaines.
- **Effort** : S
- **Vérification** : relecture de `E007.js:1`, `:462-476`, `:518-524` ; contrôle — un seul `register`, aucun import de store, aucun appel global.

## Blocages / limites inter-domaines

- La V2 s’appuie sur la passe 1 pour le bornage CSS de `.points-grid` (`overflow`, `overscroll-behavior`) : elle n’écrase pas ces règles et ne garantit pas seule l’absence de débordement latéral si la passe 1 est désactivée.
- `aria-describedby` est complété (`:214-219`, `:501`) et non remplacé : si une lentille postérieure réécrit cet attribut sans préserver les identifiants existants, le texte d’aide du laboratoire disparaîtra.
- Le calcul de visibilité suppose un en-tête `.points-grid-row.is-head` conforme au DOM de `points.js:35-38` et des cellules pourvues de `offsetLeft`/`offsetWidth`. Une refonte de la vue pourrait rendre l’indice muet ; la garde de `:475-476` neutralise alors la lentille sans erreur.
- Le défilement reste natif : la V2 ne peut pas modifier le `min-width` de la grille ni forcer un nombre de colonnes visibles, ce qui relève de la vue et des lentilles responsive (E071–E080).
- Le pas « colonne » utilise la largeur réelle du premier domaine : si les colonnes ont des largeurs hétérogènes, ce pas reste une approximation lue sur le DOM, non une garantie d’alignement sur chaque colonne.
