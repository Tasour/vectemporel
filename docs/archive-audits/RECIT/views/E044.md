# E044 — Navigation clavier

> Lentille E044 de la vue Récit — Navigation clavier. Fichiers possédés : `src/views/recit/E044.js` et `UNIFIED_AUDIT/RECIT/views/E044.md`. **Statut : 10/10 chantiers implémentés.**

Le module enregistre un unique `register('E044', ctx => { … })` auprès de `./registry.js` et injecte une seule feuille `css('recit-e044', …)`. Toutes les classes sont préfixées `recit-e044-`, les identifiants créés sont préfixés `e044-`. Zéro `console.*`, zéro réseau, zéro `Math.random()` ; les accès DOM sont gardés et chaque chantier est isolé pour qu'une défaillance locale ne casse pas le rendu. Le JS reste un enrichissement : sans lui, la vue demeure lisible.
