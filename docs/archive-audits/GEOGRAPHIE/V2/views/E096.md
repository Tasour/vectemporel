# Lentille E096 (V2) — Découpage administratif et codes ISO : de FR à 75056

- Vue : GEOGRAPHIE (`src/views/geography.js`)
- Module possédé : `src/views/geography/v2/E096.js` (remplace le stub)
- Passe 1 de référence, lecture seule : `src/views/geography/E096.js` et `UNIFIED_AUDIT/GEOGRAPHIE/views/E096.md`
- Contrat : `register('E096', ctx => { … })` avec `ctx = { viewId, stage, layout, css, el, reducedMotion() }`
- Préfixe unique : `geography-v2-e096-` (identifiants, classes, attributs et bloc CSS injecté)

## Thème

La vue GEOGRAPHIE affiche une carte et ses marqueurs, mais n'explique ni les codes qui identifient les territoires ni la hiérarchie administrative qui les structure. Un lecteur qui voit `FR` ou `75056` ne dispose d'aucune légende locale pour distinguer un code ISO d'un code COG, ni pour vérifier un code saisi.

La lentille E096 (V2) ajoute un **panneau pédagogique autonome** qui explicite les trois écritures de l'**ISO 3166-1** (alpha-2 `FR`, alpha-3 `FRA`, numérique `250`), les **six niveaux du Code officiel géographique** (de l'État à la commune `75056`), un référentiel local de dix pays, un vérificateur de code, des mesures recalculées et un **laboratoire canvas déterministe** : six rectangles emboîtés que la « descente des niveaux » révèle un à un. Un défi en cinq temps clôt l'apprentissage sur une hypothèse falsifiable.

Le contenu substantiel est du **texte sémantique réel** (`h2`, `h3`, `p`, `ul`, deux `<table>`, `fieldset role="radiogroup"`, vérificateur, défi) inséré dans le DOM : il reste lisible et indexable **même sans animation ni interaction**. Le canvas n'est qu'une surcouche : toute grandeur qu'il illustre est aussi écrite en toutes lettres dans les tableaux statiques, la liste de mesures et le paragraphe de statut `role="status" aria-live="polite"`. L'information n'est jamais portée par la seule couleur : motifs de trait, niveaux numérotés et pourcentage la doublent systématiquement.

## Bilan

**10 chantiers réellement implémentés** (E096-01 à E096-10), aucun stub ni fonction vide. Zéro appel réseau (`fetch`, XHR, `src` distant, `@import`, `url(http…)`), zéro utilisation de `console.*`, zéro `Math.random()`. Une seule boucle `requestAnimationFrame` (un seul identifiant `S.rafId` en vol, requête initiale en `startLoop()` et continuation en `tick()`), annulée quand `document.hidden` est vrai, suspendue hors écran par un `IntersectionObserver` et couplée à `ctx.reducedMotion()`. Tout le texte est du texte DOM sémantique, lisible sans JavaScript, intégralement en français. `node --check` sur le module donne **OK**.

## E096-01 — Section sémantique d'introduction (lisible sans JS) + bloc CSS isolé

- **Problème** : la vue affiche des marqueurs sans expliquer les codes qui les identifient ; un lecteur peut croire que `FR` et `75056` obéissent à la même règle. Un greffon pourrait en outre laisser fuir son style hors de la lentille.
- **Solution** : `staticFacts()` construit un `h2` « Découpage administratif et codes ISO : de FR à 75056 », un paragraphe de lede, trois paragraphes `.geography-v2-e096-fait` (trois écritures ISO 3166-1 ; hiérarchie COG en six niveaux avec référence INSEE ; le code comme convention et non comme territoire, canton signalé illustratif) et une note rappelant que tout le texte reste lisible sans interaction. Le bloc unique est injecté par `ctx.css('geography-v2-e096', CSS)` ; tous les sélecteurs et identifiants sont préfixés.
- **Impact** : le lecteur comprend immédiatement la différence entre un code ISO et un code COG, et que le panneau est autonome ; aucun style ne fuit et le contenu reste indexable sans script.
- **Risque** : une collision d'identifiants avec la passe 1 (`geography-e096-…`). Elle est écartée par le préfixe `geography-v2-e096-` et par le garde `cssOnce` intégré à `ctx.css`.
- **Vérification** : le panneau `#geography-v2-e096-panel` contient bien un `h2`, une lede et trois paragraphes de fait, visibles même si le canvas est vide ; aucune occurrence de `geography-e096-` (sans `v2`) dans le module V2.

## E096-02 — Tableau des six niveaux administratifs

- **Problème** : la hiérarchie du pays à la commune reste implicite ; sans tableau, il est impossible de comparer formats et exemples de code.
- **Solution** : `staticLevelsTable()` produit un `<table id="geography-v2-e096-levels-table">` avec `caption` et trois colonnes (Niveau, Format du code, Exemple, Libellé). Les en-têtes portent `scope="col"` et la première cellule de chaque ligne `scope="row"`. Les six lignes reprennent les niveaux État/pays (`FR`), Région (`11`), Département (`75`), Arrondissement (`751`), Canton (`7501`, marqué « format illustratif ») et Commune (`75056`).
- **Impact** : la structure emboîtée est consultable d'un coup d'œil, sous forme de texte, sans activer le moindre contrôle ; chaque niveau est associé à son format de code.
- **Risque** : attribuer un code de canton précis serait une affirmation non sourcée. La valeur `7501` est explicitement étiquetée « format illustratif » dans le libellé et rappelée comme telle dans le fait 3 et le débrief.
- **Vérification** : le tableau possède un `caption`, un `thead`, six lignes dans le `tbody` et des `th scope` ; la ligne « Canton » porte la mention « format illustratif ».

## E096-03 — Référentiel ISO 3166-1 local

- **Problème** : vérifier un code suppose de disposer d'un référentiel ; une liste importée ou générée introduirait une dépendance réseau ou des valeurs invérifiables.
- **Solution** : `staticCountriesTable()` construit un second `<table id="geography-v2-e096-countries-table">` avec `caption`, `th scope="col"` et `th scope="row"`, recensant dix pays (France `FR`/`FRA`/`250`, Allemagne, Italie, Espagne, Belgique, Suisse, Royaume-Uni, États-Unis, Canada, Japon). Les valeurs sont recopiées telles quelles dans la constante `COUNTRIES` du module, sans aucune requête.
- **Impact** : le vérificateur (E096-04/05) et la falsification (E096-10) s'appuient sur une source locale unique, stable et contrôlable.
- **Risque** : un pays du référentiel pourrait avoir un code mal formé et invalider la règle alpha-2. Le défi propose précisément de vérifier les dix lignes : c'est une hypothèse testable, pas une affirmation cachée.
- **Vérification** : le tableau contient dix lignes et quatre colonnes ; chaque alpha-2 fait deux lettres, chaque alpha-3 trois lettres, chaque code numérique trois chiffres ; aucune fonction de téléchargement n'est présente.

## E096-04 — Vérificateur de code alpha-2

- **Problème** : sans champ de saisie, le lecteur ne peut pas tester lui-même la règle de format des codes ISO.
- **Solution** : un `<label>` associé au `<input id="geography-v2-e096-code-input">` (`maxlength="2"`, `autocomplete="off"`) et un bouton « Vérifier le code » normalisent la saisie (majuscules, espaces supprimés) puis appliquent `^[A-Z]{2}$`. Un code mal formé est signalé par `aria-invalid="true"` (et une bordure dédiée) ; la touche `Entrée` dans le champ déclenche la même vérification.
- **Impact** : la distinction entre code mal formé, code bien formé mais absent du référentiel, et code reconnu est explicite et accessible.
- **Risque** : la saisie pourrait rester en majuscules dans le champ sans que l'utilisateur comprenne la normalisation. Le message de résultat et la région de statut reformulent le code traité en majuscules.
- **Vérification** : saisir `fr` puis valider affiche le décodage de `FR` ; saisir `FRA` (trop long, `maxlength` aidant) ou `1F` déclenche `aria-invalid="true"` et le message « Format invalide ».

## E096-05 — Décodage du code reconnu

- **Problème** : reconnaître un code ne suffit pas ; il faut restituer les autres écritures pour montrer qu'un même pays a plusieurs identifiants.
- **Solution** : `validateCode()` cherche le pays dans `COUNTRIES` via `findByA2()` et écrit dans `<p id="geography-v2-e096-check-result">` : `FR → France ; alpha-3 FRA ; code numérique 250.`. Le résultat est aussi repris dans la région de statut via `updateReadout()`, sans dépendre d'une animation.
- **Impact** : le lien entre les trois écritures est démontré par un exemple concret et vérifiable, disponible sous forme de texte stable.
- **Risque** : un code absent du référentiel pourrait être confondu avec un code invalide. Les trois cas produisent des messages distincts : invalide (format), hors référentiel (format correct mais inconnu), reconnu (décodage complet).
- **Vérification** : avec `FR`, le paragraphe contient « France », « FRA » et « 250 » ; avec `ZZ`, le message précise « absent du référentiel local (10 pays recensés) ».

## E096-06 — Choix du format en radiogroupe (choix unique)

- **Problème** : quatre formats de code sont présentés ; un choix unique ne doit pas être modélisé comme des bascules indépendantes (`aria-pressed`).
- **Solution** : un `<fieldset id="geography-v2-e096-formats" role="radiogroup" aria-label="…">` légendé contient quatre radios natifs de même nom `geography-v2-e096-format` : Alpha-2 (`FR`), Alpha-3 (`FRA`), Numérique (`250`) et COG communal (`75056`), chacun avec un `title` descriptif. `S.format` vit dans le module, est resynchronisé à chaque rendu par `syncRadios()` et mis à jour par `selectFormat()`.
- **Impact** : sélection native au clavier (Tab puis flèches), conforme au contrat d'accessibilité : aucun `aria-pressed` pour un choix unique ; le format choisi est repris dans le statut avec son exemple et sa longueur.
- **Risque** : l'état pourrait être perdu lors d'un `stage.replaceChildren()`. `S.format` survit au vidage du DOM et les radios sont recochés à chaque appel de `syncControls()`.
- **Vérification** : une seule case cochée à la fois ; changer de format met à jour le paragraphe de statut (par exemple « Format alpha-3 : FRA (3 caractères) »).

## E096-07 — Mesures chiffrées recalculées et comparées à une référence

- **Problème** : afficher des chiffres sans montrer leur origine ni les comparer à une référence empêche d'en juger la pertinence.
- **Solution** : `staticMeasures()` construit une liste `<ul id="geography-v2-e096-mesures">` de quatre entrées dérivées de `DEMO` recalculé depuis les données : `26 × 26 = 676` combinaisons alpha-2 ; `5 / 2 = 2,5` fois la longueur d'un alpha-2 (référence explicite : alpha-2 = 2 caractères) ; `6` niveaux administratifs ; `10` pays avec `3` écritures chacun. Le formatage `num()` impose la virgule décimale, l'espace fine et `font-variant-numeric: tabular-nums`.
- **Impact** : au moins trois grandeurs chiffrées, dont une comparée à une référence explicite, cohérentes avec les tableaux et annoncées sous forme textuelle stable.
- **Risque** : des nombres câblés en dur pourraient diverger des données. Toutes les valeurs proviennent de `COUNTRIES`, `LEVELS` et de la constante `26`, jamais d'un littéral dans l'affichage.
- **Vérification** : la liste possède quatre entrées ; `DEMO.combos = 26 * 26 = 676`, `DEMO.ratio = 5 / 2 = 2,5`, `DEMO.levels = 6`, `DEMO.countries = 10` ; la référence « 2 caractères » est écrite à côté du rapport 2,5.

## E096-08 — Laboratoire canvas unique et déterministe

- **Problème** : un schéma purement décoratif ne démontre pas l'emboîtement des niveaux ; la forme doit découler des données et rester reproductible d'un rendu à l'autre.
- **Solution** : un seul `<canvas id="geography-v2-e096-canvas">` dessine six rectangles imbriqués, un par niveau, avec un motif de trait distinct (`[]`, `[9,4]`, `[6,3]`, `[3,3]`, `[1,3]`, `[2,1,6,1]`) et un numéro + nom écrits dans le rectangle. `drawLab()` calcule la géométrie depuis `S.progress`, plafonne le DPR à 2 et ne redimensionne le tampon que si nécessaire ; la barre inférieure est graduée en six parts. Aucune graine aléatoire : tout découle de constantes et de la progression.
- **Impact** : la « descente » révèle réellement les niveaux de l'État vers la commune ; les motifs rendent la lecture possible en niveaux de gris.
- **Risque** : le canvas pourrait devenir la source exclusive d'une information. Il porte `tabindex="0"`, `role="img"`, un `aria-label` unique et un `aria-describedby` vers le paragraphe clavier ; chaque grandeur est déjà en texte dans les tableaux, la liste de mesures et le readout. Un seul canvas, un seul dessin par frame, aucune simulation instanciée en boucle.
- **Vérification** : un seul canvas est créé ; redimensionner recalcule la géométrie sans taille figée ; aucun `Math.random()` ; les six rectangles, leurs motifs, la barre graduée et le pourcentage sont dessinés à chaque rendu.

## E096-09 — Légende non chromatique, statut annoncé et contrôles accessibles

- **Problème** : une lecture en `forced-colors`, en niveaux de gris ou par lecteur d'écran ne peut pas s'appuyer sur la seule couleur, et l'état du laboratoire doit être annoncé sans saturer la région live.
- **Solution** : la légende `<p id="geography-v2-e096-legend">` nomme chaque motif (trait plein, tirets longs/moyens/courts, pointillés, point-tiret) et rappelle qu'un rectangle clair est franchi, un rectangle pâle ne l'est pas ; le nom du niveau et le pourcentage sont toujours écrits. Le readout `<p id="geography-v2-e096-readout" role="status" aria-live="polite" aria-atomic="true">` réunit format, descente, décodage et dernier message, avec une garde `S.readoutText` contre la réécriture à l'identique. Les radios mesurent 36 px, les boutons et le champ 44 px, les pouces 24 px, et `:focus-visible` est doré.
- **Impact** : toutes les distinctions survivent à la suppression des couleurs ; l'état courant est lisible de façon continue et non redondante, y compris pour une technologie d'assistance.
- **Risque** : plusieurs régions live concurrentes produiraient des annonces contradictoires. Une seule région est utilisée et toutes les grandeurs y sont réunies ; les nombres sont formatés en français (virgule décimale, espace fine).
- **Vérification** : la légende et le readout sont présents dans le DOM ; à l'état initial le readout contient bien « Format alpha-2 : FR (2 caractères) », « Descente : 0 % » et « État / pays » ; capture 390 × 844 et `forced-colors` à rejouer par l'agent maître.

## E096-10 — rAF unique, pause, mouvement réduit, clavier, défi falsifiable et idempotence

- **Problème** : la descente animée pourrait multiplier les boucles, consommer du CPU dans un onglet masqué ou ignorer la préférence de mouvement réduit ; le laboratoire doit être utilisable sans souris, l'apprentissage doit se clore par un défi réfutable, et les rendus répétés ne doivent pas dupliquer d'écouteurs.
- **Solution** : une seule boucle `requestAnimationFrame` (`tick`, identifiant unique `S.rafId`, requête initiale en `startLoop()`, continuation en fin de `tick()`) fait progresser `S.progress` de 0 à 1 à raison de `1 / 6000` par milliseconde, à partir de l'horodatage rAF uniquement, avec `dt` plafonné à 80 ms — aucune graine aléatoire. `stopLoop()`/`startLoop()` gèrent l'unique requête ; un écouteur `visibilitychange` (installé une fois, garde `visibilityBound`) annule la boucle quand `document.hidden` est vrai et la relance au retour sans saut (horodatage remis à zéro) ; un `IntersectionObserver` l'arrête hors écran. `ctx.reducedMotion()` — doublé d'un repli `matchMedia` et d'un écouteur de changement gardé par `motionBound` — interdit le démarrage de la boucle, pose l'attribut `data-geography-v2-e096-reduced="1"` et substitue un affichage instantané à 100 % ; le bouton `#geography-v2-e096-play` porte `aria-pressed` car c'est une bascule indépendante. Le canvas (`tabindex="0"`) accepte les flèches (un niveau par pas), `Début` (zéro) et `Fin` (six niveaux) ; `ensurePanel()` réutilise le panneau existant et n'attache les écouteurs locaux que sur un panneau neuf (`fresh`). L'encadré « À vous de jouer » suit les cinq temps : prédire 676 combinaisons et 6 niveaux, choisir le format COG et lancer la descente, attendre 2,5×, falsifier en cherchant un alpha-2 de trois lettres dans les dix pays, puis débrief révélé par `aria-expanded`/`aria-controls`. Un badge `#geography-v2-e096-map-badge` (`pointer-events:none`) rappelle le caractère pédagogique du tracé.
- **Impact** : zéro frame en arrière-plan, une seule boucle active au plus, progression déterministe, respect de la préférence système, navigation clavier complète, état conservé à travers les rendus et défi aligné sur les angles morts de la lentille.
- **Risque** : les écouteurs pourraient être attachés en doublon et le badge inséré plusieurs fois. Les gardes `visibilityBound`, `motionBound` et le contrôle d'existence par identifiant écartent ces cas ; les écouteurs locaux ne sont posés que sur un panneau fraîchement créé ; le garde d'entrée filtre un `ctx` incomplet et le préfixe de `viewId` limite la lentille à la vue géographique (passe 1 et V2).
- **Vérification** : masquer l'onglet annule `S.rafId` ; le nombre de rAF actifs reste ≤ 1 ; avec `prefers-reduced-motion`, la boucle ne démarre jamais, le drapeau `data-geography-v2-e096-reduced="1"` est posé et la descente s'affiche instantanément ; le bouton de débrief bascule `aria-expanded` et la visibilité du paragraphe ; tabulation complète sans piège ; capture 390 × 844 et `forced-colors` à rejouer par l'agent maître.
