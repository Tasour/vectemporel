## Chantiers

### M37-01 — Aucun énoncé historique codé en dur dans la lentille

- **Preuve** : `globe.js:373` insère une phrase toute faite (« Dix histoires documentées,
  784 cellules de couverture vérifiées… ») dont le chiffre n'est pas recalculé depuis
  `DATASET` (qui porte `points: 1746`, `validatedPoints: 845` en `dataset.js:11-13`) ;
  `registry.js:45-56` n'impose aucun contrôle sur ce que les greffons écrivent.
- **Solution** : `render()` n'émet que des libellés de schéma (« Ères », « Repères »,
  « Points », « Sources », « Claims », « Omissions », « Confiance déclarée »,
  « Verdict d’audit ») et des compteurs recomputés depuis le contexte, jamais une
  phrase historique ni une date. Écritures exclusivement via `textContent`.
- **Impact** : la lentille ne peut pas introduire de fait nouveau dans la vue Monde.
- **Risque** : un libellé de schéma pourrait être lu comme une affirmation ; ils sont
  génériques, non datés et non attribués à un acteur.
- **Effort** : S.
- **Vérification** : relecture — aucune chaîne de M37 ne contient de millésime ni de nom
  de pays ; `node --check src/views/monde/M37.js`.

### M37-02 — Distribution de confiance réelle, sans catégorie fabriquée

- **Preuve** : les valeurs réellement présentes sont `certain`, `non documenté`,
  `probable`, `disputé`, `disputed` (points pays, `dataset.js:4587, 4698`) et
  `vérifié` (points d'événement, `dataset.js:230`) ; `globe.js` ne restitue aucune
  distribution de confiance.
- **Solution** : `confidenceTally()` lit `points[].confidence` des pays du contexte,
  imprime les seules valeurs rencontrées avec leur compteur, sans traduction ni
  regroupement. Ordre déterministe (décroissant puis `localeCompare('fr')`).
- **Impact** : « probable » et « disputé » restent visibles tels quels, non convertis
  en « vrai/faux » ni en « vérifié ».
- **Risque** : vocabulaires hétérogènes (`vérifié` vs `certain`) ; affichés verbatim,
  jamais fusionnés artificiellement.
- **Effort** : S.
- **Vérification** : comparer la ligne « Confiance déclarée » avec un comptage direct
  de `country.points[].confidence` sur `dataset.js`.

### M37-03 — Verdict d'audit : état vide explicite, pas de « validé » supposé

- **Preuve** : `dataset.js:4521-4522` porte `"audit": { "verdict": "pending" }` pour
  la France (et pour les dix pays relevés) ; `audit` est un champ optionnel du schéma.
- **Solution** : `verdictOf()` ne retourne une valeur que si `audit` est un objet et
  `verdict` une chaîne ; sinon la ligne affiche « non renseigné » en italique. En vue
  d'ensemble, `verdictTally()` affiche le décompte réel (`pending 10`) ou l'état vide.
- **Impact** : aucun pays n'est présenté comme « validé » par déduction.
- **Risque** : `pending` est un verdict réel, pas un vide : il est affiché tel quel.
- **Effort** : S.
- **Vérification** : relecture — verdict agrégé égal au décompte réel des `audit.verdict`.

### M37-04 — Sources : identifiants réels uniquement, aucune URL reconstruite

- **Preuve** : `dataset.js:4244` expose `sources[]` avec `id`, `title`, `url` ; fabriquer
  une URL à partir d'un `id` (ex. une adresse déduite de `SRC-001`) inventerait une
  référence. `globe.js:325` annonce « aucun service externe » mais n'affiche aucune
  source du pays.
- **Solution** : `sourceIds()` ne lit que `source.id` (via `asText`), jamais `title` ni
  `url`. Affichage des 3 premiers identifiants réels puis `+N` où `N` est le restant
  réel ; sinon « aucune référence renseignée ».
- **Impact** : la trace de provenance est affichable sans créer de lien externe.
- **Risque** : troncature à 3 identifiants ; le solde est un compteur, pas une liste
  inventée.
- **Effort** : S.
- **Vérification** : relecture — seuls des `SRC-xxx` présents dans le dataset apparaissent.

### M37-05 — Claims et omissions : compteurs dérivés, aucune synthèse rédigée

- **Preuve** : `dataset.js:4160` (`claims`) et `dataset.js:4504` (`omissions`) existent
  au niveau pays ; aucune lentille M31–M36 n'était implémentée au départ (stubs), donc
  rien ne les restituait.
- **Solution** : `count()` sur ces tableaux, affichés sous les libellés « Claims » et
  « Omissions ». Aucun texte interprétatif, aucun jugement de véracité, aucune
  invention de contestation.
- **Impact** : la densité documentaire est mesurable sans commentaire fabriqué.
- **Risque** : le terme « claims » est repris du schéma, non traduit en « vérités ».
- **Effort** : S.
- **Vérification** : relecture — compteurs égaux aux longueurs réelles des tableaux.

### M37-06 — Suivi de sélection/survol sans inventer de relation

- **Preuve** : `globe.js:313` dérive `selected` de `state.countryId`, `:449-457` transmet
  un pays via `onHover`, et `registry.js:62-67` diffuse `{ country, code }`. Aucun de
  ces payloads ne porte de relation ; `atlas-chronologie.md:199` rappelle qu'écrire
  « contemporain » dans le DOM serait une invention.
- **Solution** : les rappels `onHover` / `onLeave` ne changent que le périmètre
  (`render(country)` ou agrégat) ; aucune relation `influence` / `contemporary` /
  `breaks_with` n'est construite. `onLeave` revient à `latest.selected` ou à la vue
  d'ensemble.
- **Impact** : le panneau ne suggère aucun lien inter-pays non documenté.
- **Risque** : un survol fantôme (`country` nul) retombe sur la sélection courante,
  jamais sur un pays deviné.
- **Effort** : M.
- **Vérification** : survol puis `onLeave` — le panneau revient au pays sélectionné ;
  aucune chaîne relationnelle dans le module.

### M37-07 — Gardes sur données : ni `NaN`, ni `undefined`, ni `[object Object]`

- **Preuve** : `ctx.countries` / `ctx.selected` sont des instantanés ; un champ absent
  (`points`, `sources`, `name`) produirait `undefined.length`, `NaN` ou une coercion
  objet dans une concaténation.
- **Solution** : `count()` ne compte que les tableaux, `asText()` ne laisse passer
  qu'une chaîne ou un nombre fini, `verdictOf()` vérifie la forme de `audit`, et toute
  écriture passe par `ctx.el(...).textContent` après `replaceChildren()`.
- **Impact** : un pays incomplet ou un contexte vide affiche un état propre, jamais une
  erreur ni une valeur de comblement.
- **Risque** : une valeur numérique `0` est une donnée réelle et reste affichée « 0 ».
- **Effort** : M.
- **Vérification** : appeler `render(null, [], ctx)` et un pays sans `points` — aucun
  `NaN`/`undefined` dans le DOM, `data-state="aggregate"` puis `"empty"`.

### M37-08 — Idempotence multi-rendus et rappels périmés

- **Preuve** : `registry.js:17-19` ne purge jamais ses tableaux de rappels, `:45-56`
  rejoue tous les greffons à chaque rendu ; `shell.js:533` vide la coque et
  `globe.js:442` relance `runMondeEnhancements`.
- **Solution** : `PANEL_ID` unique avec garde `getElementById`, CSS via `ctx.css`
  (`cssOnce`), un seul booléen `subscribed` pour enregistrer les rappels une fois, et
  `latest = ctx` relu à chaque appel : `render()` retrouve le nœud courant dans le DOM.
- **Impact** : un seul panneau et un seul couple de rappels, quel que soit le nombre de
  rendus ; aucun écouteur ajouté, aucun état de fait conservé.
- **Risque** : un rappel enregistré tôt écrit dans le panneau courant via `latest`.
- **Effort** : M.
- **Vérification** : rendre le globe 10× — `document.querySelectorAll('#monde-m37-garantie')
  .length === 1`.

### M37-09 — Accessibilité : groupe statique, pas une seconde région live

- **Preuve** : `globe.js:73-85` possède déjà `#globe-live` (`role="status"`,
  `aria-live="polite"`) alimenté par `say()` (`:148-150, 199`) ; `M17.js:118-119`
  maintient sa légende hors live pour éviter le bavardage.
- **Solution** : `#monde-m37-garantie` porte `role="group"` et un `aria-label` stable,
  jamais `role="status"`, jamais d'appel à `ctx.say()`. `pointer-events:none` évite
  tout piège de pointeur ; le panneau reste lisible en navigation.
- **Impact** : zéro annonce redondante pour les lecteurs d'écran.
- **Risque** : le survol souris seul ne déclenche pas d'annonce — comportement voulu,
  l'information est dans le DOM.
- **Effort** : S.
- **Vérification** : relecture — aucun `aria-live`/`role=status` dans M37 ; un seul
  `#globe-live` dans la vue.

### M37-10 — Zéro réseau, zéro aléa, cohérence mouvement réduit

- **Preuve** : règle 1 de `AGENTS.md` (un fichier, zéro réseau) ;
  `globe-reveal.js:85` neutralise ses transitions sous `prefers-reduced-motion` ;
  `M14-09` impose `transition:none` sur son HUD.
- **Solution** : aucune requête, aucun `Math.random`, aucune journalisation, aucune
  animation JS ; CSS injecté une fois, ombre portée retirée en
  `@media (prefers-reduced-motion:reduce)`, largeur bornée en 390×844.
- **Impact** : la lentille ne dégrade ni le budget réseau ni la préférence de mouvement.
- **Risque** : aucun (le `transform` n'est pas utilisé ici).
- **Effort** : S.
- **Vérification** : `node --check` PASS ; recherche statique sans motif
  `console.`/`Math.random`/`fetch(`/`http`/`innerHTML` dans le fichier.

## Blocages hors de mon fichier

- **A (`globe.js:373`)** : le sous-titre « 784 cellules de couverture vérifiées » est un
  nombre codé en dur, non recalculé depuis `DATASET` (`points: 1746`,
  `validatedPoints: 845`). M37 n'écrit aucun chiffre fabriqué mais ne peut pas corriger
  ce texte à la source.

  localement par `subscribed`, dette globale à porter par le maître (cf. M14-07).
- **C (`dataset.js`)** : vocabulaires de confiance hétérogènes (`vérifié`, `certain`,
  `non documenté`, `probable`, `disputé`, `disputed`). M37 les affiche verbatim plutôt
  que de forcer une normalisation qui serait une interprétation.
