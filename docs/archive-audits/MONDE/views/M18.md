# M18 — Exactitude du drapeau (domaine B : drapeau & révélation)

Source unique : `src/views/monde/M18.js` (226 lignes, greffon `register('M18', install)`).
Ce greffon contrôle la cohérence **emoji ↔ code ISO ↔ fichier SVG local**, corrige le
cadrage du drapeau (3:2 dans un cadre 2:1) et expose un diagnostic textuel — sans réseau,
ni aléa, ni timer. Les dix chantiers ci-dessous sont ceux du fichier M18.js seul.

---

## M18-01 — Périmètre strict de lecture seule et invariants du greffon

- **Titre** : Greffon autonome, lecture seule, zéro effet de bord hors panneau.
- **Preuve** : en-tête M18.js:3-16 — le greffon ne lit que `dataset.js`, `public/flags/*.svg`, `globe.js`, `globe-reveal.js`, `registry.js` et n'écrit que son propre fichier. Invariants énoncés : zéro `fetch`/XHR, zéro `Math.random`, zéro `console.*`, zéro timer, zéro animation propre, un seul id CSS (`monde-m18`), un seul nœud panneau (`PANEL_ID = monde-m18-flag`).
- **Solution** : maintenir `register('M18', install)` (ligne 226) comme unique point d'entrée ; figer localement `LOCAL_SVG_CODES` (lignes 23-25) sans test d'existence à distance ni chargement réseau.
- **Impact** : aucune dépendance réseau, aucune écriture hors du panneau, comportement stable en E2E.
- **Effort** : faible — déjà implémenté ; sert de garde-fou de régression.
- **Verification** : `grep -E 'fetch|XMLHttpRequest|Math\.random|console\.|setTimeout|setInterval' M18.js` → 0 occurrence ; un seul `ctx.css(` (ligne 209), un seul `panel.id =` (ligne 123), un seul `register(`.

## M18-02 — Décodage de l'emoji drapeau vers le code ISO

- **Titre** : 🇫🇷 → FR par les deux indicateurs régionaux U+1F1E6..U+1F1FF.
- **Preuve** : `flagEmojiCode(flag)` lignes 70-82 — exige exactement 2 caractères (`Array.from`) dont les `codePointAt(0)` sont dans `0x1F1E6..0x1F1FF`, conversion `0x41 + point - 0x1F1E6`.
- **Solution** : fonction pure, sans table de drapeaux externe ; retourne `null` pour toute entrée invalide (type non chaîne, longueur ≠ 2, code point hors plage). Le résultat alimente `emojiCode` (ligne 155) puis le message `emoji XX ≠ YY` (ligne 174).
- **Impact** : détection fiable d'un emoji incohérent avec le code ISO du pays, sans normalisation Unicode distante.
- **Effort** : faible — déjà implémenté.
- **Verification** : `flagEmojiCode('🇫🇷') === 'FR'` ; `flagEmojiCode('FR') === null` ; `flagEmojiCode('🇫') === null` ; `flagEmojiCode('🇫🇷🇷') === null`.

## M18-03 — Validation du code ISO et tri des incohérences de charge utile

- **Titre** : Un seul `issue` déterministe par inspection, priorisé.
- **Preuve** : `validCode()` lignes 84-86 (`/^[A-Z]{2}$/`) ; `inspect()` lignes 159-166 — `mismatchPayload = country.code && country.code !== code`, `mismatchEmoji = validCode(code) && emojiCode !== code`, cascade `code-invalid → payload-mismatch → emoji-mismatch → svg-missing`.
- **Solution** : prioriser le code transmis par le survol (`payloadCode`, lignes 147-149) et n'émettre qu'un diagnostic, ordonné de la façon ci-dessus.
- **Impact** : une seule anomalie actionnable par pays, sans ambiguïté sur son origine.
- **Effort** : faible — déjà implémenté.
- **Verification** : `code='ZZ'`, `country.code='FR'`, emoji 🇩🇪 → `issue='payload-mismatch'` ; code valide avec emoji 🇩🇪 → `emoji-mismatch` ; `code='fr'` → `code-invalid`.

## M18-04 — Cadrage du drapeau : SVG 3:2 dans un cadre 2:1

- **Titre** : Remplacer `cover` par `contain` pour ne pas tronquer les bandes.
- **Preuve** : commentaire CSS lignes 39-40 — le SVG est 60x40 (3:2), le cadre `.gr-figure` est 2:1 ; `background-size:cover` recoupe ~25 % de la hauteur et tronque les bandes horizontales.
- **Solution** : règle `#globe-reveal .gr-figure > .gr-flag { background-size:contain; background-repeat:no-repeat; background-position:center center; background-color:transparent; }` (lignes 41-46).
- **Impact** : bandes et emblèmes intacts sur le drapeau révélé (notamment FR, DE, IT), fidélité visuelle restaurée.
- **Effort** : faible — 4 déclarations CSS.
- **Verification** : rendu 1658×1150 et 390×844 — le drapeau FR affiche ses trois bandes intégrales et le carré bleu complet, aucune bande coupée aux bords du cadre.

## M18-05 — Pile de polices emoji 100 % locale

- **Titre** : Glyphes colorés sans téléchargement de police.
- **Preuve** : commentaire ligne 47 et règle lignes 48-51 — `"Apple Color Emoji","Segoe UI Emoji","Noto Color Emoji",sans-serif` avec `font-variant-emoji:emoji` ; aucun `@font-face`, aucune URL de glyphe.
- **Solution** : s'appuyer uniquement sur les polices système déjà présentes, avec repli `sans-serif` si aucune police emoji colorée n'est disponible.
- **Impact** : cohérence avec la règle zéro réseau ; aucun chargement de police, aucun décalage de glyphe.
- **Effort** : faible — déjà implémenté.
- **Verification** : styles calculés de `.globe-country-flag` — `font-family` ne contient que des familles locales ; onglet Réseau : aucune requête de police.

## M18-06 — Garde-fou d'appartenance de l'ère au pays

- **Titre** : Ne jamais projeter l'ère d'un autre pays sur le drapeau affiché.
- **Preuve** : `eraFor(ctx, country)` lignes 94-102 — retour `null` si `state.countryId !== country.id` ; l'ère n'est lue que si elle appartient au pays courant.
- **Solution** : conditionner la lecture de `country.eras[state.eraIndex]` à l'égalité d'identifiant ; n'ajouter `ère ${era.name}` au texte que si `era` est non nul (lignes 180, 188).
- **Impact** : le panneau rappelle que le drapeau est « repère du pays, non drapeau de l'ère » (ligne 178) ; aucune attribution croisée.
- **Effort** : faible — déjà implémenté.
- **Verification** : sélectionner le pays A puis survoler le pays B → `data-m18-era` vide pour B ; sélectionner B → `ère …` apparaît avec l'id de B.

## M18-07 — Priorité du code transmis par `notifyMondeHover`

- **Titre** : Le code du payload gagne, repli par résolution du pays.
- **Preuve** : commentaire lignes 192-194 — `notifyMondeHover` transmet `{ country, code }` (registry.js:70-71) ; `handleHover()` lignes 195-202 utilise `data.code` en priorité et résout le pays via `ctx.countries.find(item.code === data.code)` si l'objet `country` manque (survol moteur).
- **Solution** : garder la résolution par code comme repli, puis appeler `inspect(ctx, country, data.code)` avec le code du payload.
- **Impact** : survol clavier/pointeur et survol moteur produisent le même diagnostic, indépendamment de la présence de l'objet pays.
- **Effort** : faible — déjà implémenté.
- **Verification** : hover `{ code: 'JP' }` seul → panneau `Drapeau JP …` ; hover `{ country: paysFR, code: 'DE' }` → diagnostic sur `DE` avec `payload-mismatch`.

## M18-08 — Réabonnement idempotent avec jeton anti-périmé

- **Titre** : Un nœud panneau, des callbacks jamais périmés.
- **Preuve** : commentaire lignes 204-206 — registry.js:48-50 purge les callbacks à chaque rendu ; `install()` lignes 207-224 réabonne via `ctx.onHover`/`ctx.onLeave`, avec `const token = ++installToken` et exécution seulement si `token === installToken`.
- **Solution** : incrémenter `installToken` à chaque `install()`, garder `ensurePanel()` unique par `PANEL_ID` (lignes 116-132) en réutilisant un panneau déjà `isConnected`.
- **Impact** : aucun ancien callback ne réécrit le panneau après un rendu ; un seul nœud dans le DOM.
- **Effort** : moyen — logique de jeton et garde `panel.isConnected`.
- **Verification** : forcer 3 rendus puis survols — `document.querySelectorAll('#monde-m18-flag').length === 1` ; un survol émis avant le dernier rendu ne modifie pas le panneau.

## M18-09 — Instrumentation : compteur de couverture et attributs E2E

- **Titre** : Diagnostic mémorisé par code et exposé sous forme d'attributs.
- **Preuve** : `statuses = new Map()` (ligne 68), `anomalyCount()` (lignes 88-92), `statuses.set(code, …)` (ligne 168), `writePanel()` posant `data-m18-code`, `data-m18-emoji`, `data-m18-svg`, `data-m18-fidelity`, `data-m18-era`, `data-m18-issue` (lignes 104-114) et le suffixe `vérifiés N · anomalies M` (ligne 181).
- **Solution** : dédupliquer les inspections par code et exposer l'état en attributs de données plutôt qu'en texte seul.
- **Impact** : suivi du nombre de pays vérifiés et cibles E2E stables pour les tests d'anomalies.
- **Effort** : faible — déjà implémenté.
- **Verification** : survoler FR deux fois → `vérifiés 1` (pas 2) ; sur les 10 codes de `LOCAL_SVG_CODES` (CN, DE, EG, ES, FR, GB, IN, IT, JP, US), `data-m18-svg='present'`, et `'missing'` pour tout code hors liste.

## M18-10 — Diagnostic textuel accessible et fidélité documentée

- **Titre** : Un texte lisible, indexable et transparent sur les SVG stylisés.
- **Preuve** : `STYLIZED` lignes 27-36 — 6 drapeaux notés stylisés (CN, EG, ES, GB, IN, US), sans fait historique inventé ; `ensurePanel()` lignes 116-126 crée un `<p>` avec `role="group"` et `aria-label="Exactitude du drapeau"` ; `describeSelected()` lignes 134-141 affiche l'invitation au survol ; `writePanel()` joints (lignes 171-182) décrivent emoji, SVG, fidélité et ère.
- **Solution** : produire un texte complet (emoji cohérent/incohérent, SVG présent/absent, fidèle/stylisé, ère éventuelle, compteurs) et mentionner explicitement la stylisation quand le SVG local est simplifié.
- **Impact** : diagnostic compréhensible au clavier et en lecture d'écran ; limites graphiques des SVG locaux rendues visibles.
- **Effort** : faible — déjà implémenté.
- **Verification** : au chargement, texte d'invitation présent ; survol de EG → `SVG stylisé : aigle remplacé par un motif géométrique` ; survol de FR → `SVG fidèle` ; `aria-label` unique et présent dans le DOM.
