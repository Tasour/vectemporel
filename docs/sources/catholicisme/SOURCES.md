La page Wikipédia FR « Catholicisme » est surtout thématique : elle donne le vocabulaire, la doctrine et la place du catholicisme dans le monde. La page Grokipedia fournit une chronologie détaillée. Les deux se complètent ; les repères chronologiques de Grokipedia sont recoupés avec les repères doctrinaux de Wikipédia quand c'est possible.

## Règle appliquée

- Fait présent dans les deux sources → noyau commun, retenu.
- Fait présent seulement dans Grokipedia → retenu par défaut, marqué `grokipedia`.
- Conflit ou doute → vérification web, décision tracée dans `convergence.md`.
- Préférence par défaut Grokipedia pour l'interprétation, jamais pour un chiffre incertain.
- Aucun paragraphe n'est copié : la prose du rapport est originale.
- La fenêtre du récit est celle de la donnée Chronas (`catholic` de 868 à 2000), pas l'âge supposé de la religion : les faits antérieurs à 868 sont cités comme contexte, jamais comme jalon.
