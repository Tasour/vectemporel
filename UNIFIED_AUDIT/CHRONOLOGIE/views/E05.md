# Lentille E05 — Navigation clavier (vue Chronologie)

**Module** : `src/views/chronology/E05.js` — `register('E05', ctx => { … })`
**Pont de chargement** : `src/views/chronology/E005.js` → `import './E05.js'`
**CSS** : `ctx.css('chronology-e05', …)` — un seul bloc, injecté une fois par `cssOnce`
**Statut** : **10/10 chantiers implémentés** (E05-01 … E05-10)

## Contexte et contrat

La coque reconstruit `#app` à chaque rendu (`shell.js:533`) : le `stage` et le
`layout` sont de nouveaux nœuds, et le routeur clavier global (`keyboard.js`)
gère déjà les flèches, `Entrée`, `?` et `Échap`. La lentille est donc strictement
**additive** : aucun gestionnaire global de touche n'est ajouté, aucune touche
déjà routée n'est détournée, aucun attribut existant n'est supprimé.

Deux éléments de l'échafaudage sont à noter :

1. Le README de la vague annonce `E01.js … E100.js` alors que l'`index.js`
   importe `E001.js … E100.js`. Le module est livré sous le nom demandé
   `E05.js` ; `E005.js` est réduit à un import de ce module afin que le rendu
   l'exécute réellement. Les modules ES étant évalués une seule fois, le
   `register('E05', …)` n'est appelé **qu'une fois**, même si les deux chemins
   sont importés.
2. `_diagnostics.js:72` masque tout nœud dont l'identifiant correspond à
   `/^(e\d\d[-_ ]|.*-e\d\d)/` et qui est un enfant direct de `body`, `stage` ou
   `layout`. Les nœuds visibles de la lentille utilisent donc le préfixe
   `chrono-kbd-` (sans `-e05`) et sont insérés dans `.chronology-main`, jamais
   directement dans `stage`/`layout`. L'identifiant `chronology-e05` est réservé
   au `<style>` injecté dans `<head>`, hors du champ de ce marquage.

## Détails techniques

- **Un seul `register('E05', …)`**, un seul bloc CSS, zéro `Math.random()`,
  zéro `console.*`, zéro `fetch`/XHR/`src` distant, zéro timer, zéro
  `IntersectionObserver`, zéro écouteur `keydown` global.
- **Identifiants uniques** : `chronology-e05` (style), `chrono-kbd-help`,
  `chrono-kbd-skip-events`, `chrono-kbd-skip-aside`, `chrono-kbd-readout`,
  `chrono-kbd-live`. Les attributs `data-chrono-kbd-role` / `-tag` servent
  uniquement à la restauration de focus.
- **Focus visible** : contour `2px` avec `outline-offset:2px` sur résumé, liens
  d'évitement, bandes d'ères, cartes de repères, puces, recherche, bouton retour
  et cibles d'évitement. Cible minimale `24px` pour le résumé, `32px` pour les
  liens ; `prefers-reduced-motion` neutralise les transitions.
- **Résilience** : tous les pointeurs de rendu sont des variables de module
  (`currentLayout`, `trackedFocus`) ; les écouteurs locaux meurent avec le
  `stage` reconstruit, l'unique écouteur `document` est armé une fois
  (`focusBound`). Une lentille défaillante est neutralisée par
  `registry.js:39-42` sans interrompre le rendu.
