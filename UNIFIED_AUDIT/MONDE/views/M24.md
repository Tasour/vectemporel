# M24 — Raccourcis clavier du globe (domaine C : ergonomie & interaction)

Lentille : M24. Fichier possédé : `src/views/monde/M24.js`.
Lectures seules : `src/views/globe.js`, `src/platform/keyboard.js`, `src/views/monde/registry.js`,
`src/views/monde/M05.js`, `src/views/monde/M13.js`, `src/views/monde/M28.js`,
`UNIFIED_AUDIT/views/atlas-globe.md`, `UNIFIED_AUDIT/MONDE/README.md`.
Aucun fichier partagé modifié, aucun réseau, aucun `Math.random`, aucun `console.*`,
aucun sélecteur de test touché. 10 chantiers, tous implémentés.

## État des lieux (preuves de lecture)

- `keyboard.js:199` installe l'unique routeur en **capture** sur `document` ; `handle()` (:123-197)
  ignore les modificateurs (:127), les cibles éditables (:129), ce qui est `defaultPrevented`
  (:125, contract T2-10) et, en vue globe, ressort avant flèches/Entrée/Espace (:169).
- `globe.js:281` possède l'écoute `keydown` du host : flèches, `Home`, `End`, `Entrée` (:202-230).
  La coque récrée la scène à chaque émission du store, mais le host `#globe-canvas` est persisté
  par `ensure()` (:263-292).
- `M05.js:202-208, 288` possède le zoom clavier `+ = − _ PageUp PageDown` sur le même host.
- `M13.js:172-186` observe `Échap` en vue globe **sans** `preventDefault` ; `M28.js` refuse
  explicitement toute touche globale (:13) et ouvre son aide par un bouton.
- Il reste donc trois touches libres et utiles : `a`, `v`, `0`. Le registre `VECTEMPOREL_KEYS.map`
  (:203-205) et `modalState()` (:210) permettent de les garantir à l'exécution.

## M24-01 — Un seul écouteur `keydown`, posé une fois sur le host persistant

- **Preuve** : un greffon naïf ajouterait un `addEventListener` par touche et, `runMondeEnhancements()`
  étant rejoué à chaque rendu (`registry.js:45-55`), empilerait des douzaines d'écouteurs sur le host.
- **Solution** : `attachOnce()` garde `attached` au niveau module et n'écoute que le host
  (`#globe-canvas`, stable d'un rendu à l'autre). Le fichier ne contient qu'un seul
  `addEventListener('keydown', onKeyDown)`.
- **Impact** : exactement un écoute M24, sans duplication ni dérive de compteurs.
- **Risque** : si le premier rendu n'avait pas de host, la garde bloquerait toute installation
  ultérieure ; `attachOnce()` pose `attached = true` seulement après un `host` valide.
- **Effort** : S
- **Vérification** : `grep -c "addEventListener('keydown'" src/views/monde/M24.js` → 1 ; basculer
  1→2→1 trois fois → `VECTEMPOREL_M24.ready() === true` et `stats().handled` croît d'un par touche.

## M24-02 — Aucune touche réservée : garde dynamique du routeur + liste statique

- **Preuve** : les touches de vue (`1`–`6`, `m/c/r/g/s/p`) sont dans `VECTEMPOREL_KEYS.map`
  (`keyboard.js:204`) et résolues avant le retour globe (:160-166) : les intercepter casserait la
  navigation. Avant `initKeyboard()`, le bus n'existe pas encore.
- **Solution** : `ownerOf(key)` consulte d'abord `window.VECTEMPOREL_KEYS.map` (propriété propre,
  pas prototype), puis un `Set` statique `FOREIGN` couvrant `?`, `Escape`, `Enter`, ` `, flèches,
  `Home/End`, `+ = − _ PageUp PageDown` (M05), `Tab`, `Backspace`, `Delete`. Toute touche possédée
  sort avant le `preventDefault()` de M24.
- **Impact** : si le routeur ajoute un jour `a`, `v` ou `0`, M24 s'efface automatiquement.
- **Risque** : le bus est publié par `app.js` ; s'il est absent, la liste statique reste la source
  de repli — documentée et vérifiable.
- **Effort** : S
- **Vérification** : `VECTEMPOREL_M24.reserved()` contient `?`, `Escape`, `PageUp` ; appuyer `1`,
  `m`, `?`, `PageUp` → `stats().conflictsAvoided` augmente et `stats().handled` reste stable.

## M24-03 — Respect de la capture du routeur et des gardes T2

- **Preuve** : le routeur écoute en capture (:199) donc **avant** M24 (host, phase bulle) ; il
  vérifie `defaultPrevented` (:125), les modificateurs (:127), les champs éditables (:129) et le
  gel de modale (:157). M24 ne peut pas « voler » une touche consommée en amont.
- **Solution** : `onKeyDown()` sort sur `event.defaultPrevented`, `ctrl/meta/alt`, cible
  `INPUT/TEXTAREA/SELECT/contentEditable`, modale ouverte (`modalState()` avec repli
  `state.helpOpen/detailOpen`) et vue autre que `globe`. Le `preventDefault()` n'est posé qu' ensuite,
  uniquement pour nos trois touches.
- **Impact** : cohérence totale avec DISPATCH_ORDER du routeur, zéro action fantôme.
- **Risque** : l'écoute en bulle rend le `preventDefault()` « tardif » pour le routeur ; c'est
  sans conséquence puisque nos touches ne sont pas dans sa map (M24-02).
- **Effort** : M
- **Vérification** : avec l'aide ouverte, `a` ne change pas l'état de la légende ; dans un champ
  de recherche, `v` ne bascule pas la rotation.

## M24-04 — `a` : légende des raccourcis sans second écouteur

- **Preuve** : `M28.js` fournit une aide contextuelle mais refuse toute touche globale (:13) ;
  un nouveau bouton ajouterait un second écouteur `click` interdit par la consigne.
- **Solution** : `a` bascule l'attribut natif `open` d'un `<details id="monde-m24-legend">`.
  Le résumé `<summary>` reste cliquable nativement : zéro `addEventListener` supplémentaire.
- **Impact** : la liste complète des raccourcis (avec leur propriétaire) est consultable au clavier
  comme à la souris, sans déplacer le focus.
- **Risque** : la coque recréant la scène, le nœud peut être détaché ; `ensureLegend()` le retrouve
  par id et le ré-ancre dans la scène courante.
- **Effort** : S
- **Vérification** : focus sur `#globe-canvas`, `a` → `#monde-m24-legend[open]` ; `a` → fermé ;
  aucun doublon après trois rendus.

## M24-05 — `v` : basculer la rotation via le bouton existant, pas le moteur

- **Preuve** : `globe.js:351-362` crée le bouton de pause, le seul contrôle du globe à porter
  `aria-pressed` ; `M07.js` interdit tout `open()/close()` parasite et `M10` gère le mouvement
  réduit. Un greffon qui piloterait `engine` directement créerait un second propriétaire.
- **Solution** : `toggleRotation()` repère l'unique `button[aria-pressed]` dans `.globe-controls`
  et appelle `.click()`. `globe.js` reste maître de `paused`, de `syncEngine()` et de l'annonce
  dans `#globe-live` ; M24 ne publie aucun message redondant.
- **Impact** : raccourci mémotechnique (« vitesse ») pour une commande déjà sans touche dédiée.
- **Risque** : si le bouton est absent (re-render en cours), le repli annonce « commande
  indisponible » via `ctx.say()` plutôt que de modifier l'état.
- **Effort** : S
- **Vérification** : `v` → `aria-pressed` du bouton s'inverse et `#globe-live` contient
  « Rotation en pause. » ; `data-globe-active` reste sous le contrôle exclusif de `globe.js`.

## M24-06 — `0` : situation annoncée dans la région live unique

- **Preuve** : `#globe-live` (`globe.js:73-85`) reçoit déjà les annonces de pays, de zoom et de
  rotation ; `M08.md` et `M14.js:73-75` interdisent un second `aria-live` pour éviter les doublons.
- **Solution** : `situation()` compose un texte stable — pays courant (ou absence), nombre de pays,
  rappel `a v 0` — et le passe à `ctx.say()`. Un cache `lastSituation` évite de réécrire un texte
  identique ; marqueur `host.dataset.m24Situation = '1'` auditable.
- **Impact** : touche de « où suis-je ? » immédiate, utile après un changement de vue ou un re-render.
- **Risque** : bavardage si la touche est répétue ; le cache neutralise les appels redondants.
- **Effort** : S
- **Vérification** : après sélection d'un pays, `0` → `#globe-live` contient le nom du pays et
  « 10 pays documentés » ; un second `0` n'ajoute aucune annonce.

## M24-07 — Légende sémantique, lisible sans JS et non portée par la couleur

- **Preuve** : la consigne de `globe.js:425` ne décrit que flèches/Entrée/survol ; les touches
  de zoom vivent dans `M05.js:27` et l'aide générale dans la coque. Aucune vue ne les rassemble.
- **Solution** : dix entrées `<li>` avec `<kbd>` et un libellé texte explicite nommant le
  propriétaire (globe.js, M05, routeur, M24), construites avec `ctx.el()` et `textContent`.
  `<details>/<summary>` fonctionne même si le greffon ne s'exécute pas.
- **Impact** : autodécouverte des raccourcis, y compris en lecteur d'écran et sans mouvement.
- **Risque** : chevauchement avec le badge M05 en petit écran ; media query 620 px qui étire la
  légende en bas et réduit la largeur des `<kbd>`.
- **Effort** : S
- **Vérification** : en 390×844, `#monde-m24-legend` ne déborde pas horizontalement ; chaque
  ligne est lisible en mode navigation (pas de texte dans `aria-hidden`).

## M24-08 — `aria-keyshortcuts` complété, focus visible conservé

- **Preuve** : le host est partagé par 50 lentilles ; écraser son `aria-keyshortcuts` écraserait
  une valeur posée par une autre (aucune ne le fait aujourd'hui, mais le contrat reste ouvert).
- **Solution** : `markHost()` fusionne `a v 0` avec les jetons déjà présents, sans doublon.
  Le CSS de M24 ne touche qu'à `#monde-m24-legend` ; le `:focus-visible` du `<summary>` est
  renforcé, les cibles tactiles natives restent celles du navigateur.
- **Impact** : annonce correcte des raccourcis par le lecteur d'écran, sans régression d'accessibilité.
- **Risque** : la valeur fusionnée peut contenir des jetons inconnus de M24 ; ils sont conservés
  tels quels, par principe de non-destruction.
- **Effort** : S
- **Vérification** : `getAttribute('aria-keyshortcuts')` contient `a v 0` une seule fois après
  trois rendus ; le focus sur `<summary>` montre un contour visible.

## M24-09 — Surface de diagnostic auditable, zéro console

- **Preuve** : les autres lentilles exposent `VECTEMPOREL_M05` (`M05.js:291-301`) et
  `mondeDiagnostics()` (`registry.js:70-72`) ; sans surface équivalente, l'agent maître ne peut
  pas vérifier l'absence de conflit.
- **Solution** : `window.VECTEMPOREL_M24` expose `map()`, `reserved()`, `owners()`, `stats()`
  (`handled/ignored/conflictsAvoided`), `chantiers()` (10 entrées) et `ready()`. Aucun `console.*`.
- **Impact** : contrôles automatisables en fin de vague, sans instrumenter le moteur ni la coque.
- **Risque** : la surface est en lecture seule (getters returning copies) : aucun test ne peut
  modifier l'état interne du greffon.
- **Effort** : S
- **Vérification** : `VECTEMPOREL_M24.chantiers().length === 10` ; `map()` ne contient que `a`, `v`, `0`.

## M24-10 — Souveraineté des domaines voisins documentée et vérifiée

- **Preuve** : cinq propriétaires se partagent le clavier du globe : routeur (`keyboard.js`),
  `globe.js`, M05 (zoom), M13 (Échap/survol), M28 (aide). Toute tentative de M24 de reprendre
  une de ces touches produirait une double action.
- **Solution** : la table `owners()` de M24-09 et la légende de M24-07 attribuent explicitement
  chaque touche ; `FOREIGN` (M24-02) en est l'application. M24 ne touche ni flèches, ni zoom,
  ni `?`, ni Échap, ni Entrée, ni Espace : ces chantiers restent la propriété de leurs lentilles.
- **Impact** : arbitrage maître simplifié : un conflit se lit dans `reserved()`/`owners()` avant
  tout test E2E.
- **Risque** : un ajustement du routeur (nouvelle touche de vue) est absorbé par la garde
  dynamique de M24-02, mais la légende statique devrait alors être relue par l'agent maître.
- **Effort** : S
- **Vérification** : `owners()` couvre bien les cinq propriétaires ; `grep` sur M24.js confirme
  zéro référence à `ArrowLeft`, `PageUp`, `?` ou `Escape` dans le `switch` d'action.

## Statut d'implémentation

Les 10 chantiers sont implémentés dans `src/views/monde/M24.js`. Un seul écouteur `keydown`,
posé sous garde sur le host persistant ; un seul `register('M24', …)`. CSS injecté une fois via
`ctx.css('monde-m24', …)`, légende `#monde-m24-legend` à ID unique avec garde d'existence.
Zéro réseau, zéro `Math.random`, zéro `console.*`, aucun autre fichier modifié.

## Blocages

- Aucun bloquant fonctionnel. M24 n'ajoute que trois touches libres (`a`, `v`, `0`) et s'efface
  automatiquement si le routeur venait à en revendiquer une (M24-02) : le constructeur de la
  légende devrait alors être mis à jour par l'agent maître.
- Le `preventDefault()` de M24 intervient en phase bulle, après le routeur : ce n'est pas un
  problème puisque les touches de M24 sont absentes de sa map, mais tout futur raccourci envoyé
  à M24 devra passer le filtre `ownerOf()` (M24-02).
