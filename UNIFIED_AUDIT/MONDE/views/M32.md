# M32 — Noms et libellés des pays

Lentille M32 — domaine D : données & sémantique.
Fichier possédé : `src/views/monde/M32.js`. Lectures seules : `src/data/dataset.js`,
`src/views/globe.js`, `styles.css`, `src/views/globe-reveal.js`,
`src/views/monde/registry.js`, `src/views/monde/M17.js`. Aucun autre fichier
modifié, aucune donnée historique inventée, zéro réseau, zéro `Math.random`,
aucun `console.*`.

Tous les noms, identifiants (`id`, `code`) et compteurs (ères, repères, points)
affichés par M32 proviennent de `ctx.countries`, c'est-à-dire du dataset généré.
Le reste est déduit du DOM courant (`#globe-choices`, `.globe-here`,
`host.dataset.globeSelected`). Aucune graphie de pays n'est recodée en dur.

## M32-01 — Graphie exacte des noms propres non contrôlée

- **Titre** : rien ne garantit que le texte rendu reste identique au nom du dataset.
- **Preuve** : `dataset.js:18, 9307, 16087, 55042` portent « France », « Royaume-Uni », « États-Unis », « Égypte » (diacritiques et traits d'union). `globe.js:409` écrit `country.name` verbatim, mais une correction de casse a déjà été nécessaire ailleurs : `globe-reveal.js:82-83` appliquait `text-transform:uppercase`, neutralisé uniquement sur `.gr-caption` par M17.
- **Solution** : `refresh()` associe chaque bouton à son pays via `button.dataset.index` (`globe.js:402`) et compare strictement `.globe-country-name`.textContent à `country.name`. Résultat marqué ✓/⚠ dans la table et exposé en `data-m32-graphy`.
- **Impact** : toute altération future de la graphie devient visible dans le panneau, sans lecture du code source.
- **Risque** : l'index `data-index` est l'ordre du dataset (`globe.js:397`) ; il est stable dans `ctx.countries`. Aucun pays n'est supposé par son nom.
- **Effort** : M
- **Vérification** : `node --check` PASS ; relecture — `data-m32-graphy="ok"` attendu avec les 10 noms du dataset.

## M32-02 — Libellé visible tronqué par ellipsis

- **Titre** : le nom complet peut être masqué par le styles.
- **Preuve** : `styles.css:188` — `.globe-country-name{overflow:hidden; text-overflow:ellipsis; white-space:nowrap}`. « Royaume-Uni » (11 caractères) et « États-Unis » (10 caractères) sont les libellés les plus longs du dataset (`dataset.js:9307, 16087`) ; la colonne de décision mesure 420 px (`styles.css:118`) et se réduit en dessous de 900 px (`styles.css:320-326`).
- **Solution** : M32 pose `title = country.name` sur chaque `.globe-country-name`. Le compteur d'attributs posés alimente le contrôle `title` et `data-m32-title`. Aucun sélecteur de test n'est renommé, aucun espace du bouton n'est modifié.
- **Impact** : le nom intégral reste disponible au survol même quand l'ellipse est active.
- **Risque** : l'info native du navigateur peut doubler une info existante ; elle est courte, non live et porte uniquement une donnée du dataset.
- **Effort** : S
- **Vérification** : relecture — chaque `.globe-country-name` porte un `title` égal à son texte.

## M32-03 — Nom accessible des boutons jamais audité

- **Titre** : le nom accessible d'un bouton pays est une concaténation non vérifiée.
- **Preuve** : `globe.js:404-413` construit le bouton avec le numéro (`aria-hidden` en `:406`), le drapeau (`aria-hidden` en `:408`), le nom (`:409`), la ligne d'ères/repères/points (`:412`) et la couverture (`:413`). Le code ISO n'apparaît pas dans le bouton ; M17 ne l'affiche que dans la légende de survol (M17-06).
- **Solution** : `accessibleText()` parcourt les nœuds, exclut les sous-arbres `aria-hidden="true"` et `hidden`, normalise les espaces, puis vérifie que le nom accessible **commence** par `country.name`. Résultat en `data-m32-accessible`.
- **Impact** : le premier mot entendu par un lecteur d'écran est toujours le nom du pays, pas le numéro ni la couverture.
- **Risque** : l'écrasement du nom accessible par un `aria-label` aurait supprimé les compteurs ; M32 ne touche donc pas à l'ARIA des boutons, il la contrôle seulement.
- **Effort** : M
- **Vérification** : relecture de `accessibleText()` et de `data-m32-accessible="ok"`.

## M32-04 — Désalignement de l'identifiant court du Royaume-Uni

- **Titre** : `id`, `code` et `name` ne sont jamais présentés côte à côte.
- **Preuve** : `dataset.js:9306-9310` porte `id: "uk"`, `name: "Royaume-Uni"`, `code: "GB"`. Les neuf autres pays ont un `id` slug entier (`france`, `usa`, `germany`...) ; seul `uk` est un jeton de deux lettres, et c'est le seul qui puisse être comparé directement au code ISO `GB`, dont il diverge.
- **Solution** : la table affiche « Nom (dataset) · id · code » pour les dix pays. La détection `id.length === 2 && id.toUpperCase() !== code` isole le seul cas `uk` / `GB`, compté dans `data-m32-divergences`. Le verdict précise « documenté, jamais corrigé ici (dataset en lecture seule) ».
- **Impact** : le désalignement est explicite et attribué à sa source, sans inventer de nouveau code ni de nouveau nom.
- **Risque** : ne pas confondre avec M33 (codes ISO et drapeaux). M32 audite la cohérence des trois identifiants ; il n'ajoute aucun badge de code dans le bouton.
- **Effort** : S
- **Vérification** : relecture — `data-m32-divergences="1"` et mention `uk` / `GB` dans le verdict.

## M32-05 — Ordre alphabétique français non recoupé

- **Titre** : l'ordre d'affichage repose sur une collation qui n'est pas contrôlée.
- **Preuve** : `globe.js:395` trie avec `a.name.localeCompare(b.name, 'fr')`. L'ordre réel obtenu est : Allemagne, Chine, Égypte, Espagne, États-Unis, France, Inde, Italie, Japon, Royaume-Uni — « Égypte » et « États-Unis » se classent sous E, et non en fin de liste comme le ferait un tri ASCII.
- **Solution** : `refresh()` recalcule l'ordre attendu depuis `ctx.countries` avec la même collation `'fr'`, puis compare la séquence des `data-index` des boutons dans le DOM. Résultat en `data-m32-order`.
- **Impact** : une régression de tri (changement de locale, réordonnancement manuel) est détectée sans relecture visuelle des dix lignes.
- **Risque** : `localeCompare` dépend de l'implémentation du moteur ; M32 utilise exactement le même appel que `globe.js`, donc les deux convergent par construction, sans valeur codée en dur.
- **Effort** : M
- **Vérification** : relecture — `data-m32-order="ok"` et ordre de la table identique à celui de `globe.js:395`.

## M32-06 — Unicité des libellés non garantie

- **Titre** : deux pays pourraient porter le même libellé sans que le choix devienne ambigu visiblement.
- **Preuve** : `ctx.countries` contient 10 noms distincts et 10 codes distincts (relevé sur `dataset.js`), mais aucune vue ne vérifie cette unicité. Le drapeau est `aria-hidden` (`globe.js:408`) et le code ISO n'est pas dans le bouton (`globe.js:409-413`) : le nom est donc le seul repère textuel.
- **Solution** : deux comparaisons de `Set` sur `ctx.countries` (noms et codes) alimentent le contrôle `unique` et `data-m32-unique`. Aucun nom n'est supposé : seules les tailles des ensembles sont comparées à `countries.length`.
- **Impact** : un doublon de libellé introduit dans le dataset serait signalé immédiatement.
- **Risque** : l'unicité du `code` est contrôlée séparément de celle du `name` ; un code dupliqué avec des noms distincts est donc détecté aussi.
- **Effort** : S
- **Vérification** : relecture — `data-m32-unique="ok"` avec 10 noms et 10 codes.

## M32-07 — Identité portée par le drapeau ou la couleur

- **Titre** : le texte seul doit identifier un pays, sans dépendre du drapeau ni de la teinte.
- **Preuve** : `globe.js:407-408` crée le drapeau puis le marque `aria-hidden="true"` ; `dataset.js:20 (`color`), 9306-9310 (`code/name`)` fournit `color`, mais `globe.js:404-413` ne l'insère jamais dans le texte du bouton. Pour un lecteur d'écran ou en repli sans WebGL, seul le nom subsiste.
- **Solution** : M32 vérifie pour chaque bouton que `.globe-country-name` existe, n'est pas vide, et que le drapeau adjacent est bien `aria-hidden="true"`. Contrôle `textOnly`, exposé en `data-m32-text-only`.
- **Impact** : la liste reste compréhensible sans vision et sans interprétation des couleurs.
- **Risque** : les drapeaux emoji eux-mêmes ne sont pas jugés ici (domaine M18) ; M32 vérifie seulement qu'ils ne portent pas l'information textuelle.
- **Effort** : S
- **Vérification** : relecture — `data-m32-text-only="ok"`.

## M32-08 — Titre de la vue et libellé de sélection non recoupés

- **Titre** : le libellé « Sélection courante » peut diverger de l'état réel.
- **Preuve** : `globe.js:370` crée l'unique `h1` « Choisir un pays », `:376-378` écrit `.globe-here` avec `Sélection courante : ${selected.name}` ou « Aucun pays sélectionné », et `:394` pose `host.dataset.globeSelected = currentCode`. Trois sources, aucun recoupement.
- **Solution** : M32 exige un seul `.globe-list h1` au texte exact, puis dérive le pays sélectionné du code dans `ctx.host.dataset.globeSelected` et vérifie que `.globe-here` contient son `name` (ou « Aucun pays » en l'absence de code). Contrôle `labels`, `data-m32-labels`.
- **Impact** : le libellé de situation reste aligné sur l'état unique, sans lire `ctx.selected` ni le store.
- **Risque** : `ctx.host` est fourni par le contrat ; si le jeu de données change de code, la recherche porte sur `country.code` et non sur une chaîne codée en dur.
- **Effort** : M
- **Vérification** : relecture — `data-m32-labels="ok"` dans les deux états (sélectionné / aucun).

## M32-09 — Compteurs de libellés non recoupés avec le dataset

- **Titre** : le nombre de pays annoncé et le détail chiffré ne sont pas vérifiés ensemble.
- **Preuve** : `globe.js:373` annonce « Dix histoires documentées », `:379-380` affiche `${DATASET.countries.length} pays · ${meta.events} repères...` ; `countryMeta()` (`:124-133`) calcule ères, repères, points et domaines sans témoin dans la liste.
- **Solution** : la table M32 affiche par pays `eras.length / events.length / points.length`, tous lus dans `ctx.countries` (ex. France : 9/57/140, recalculé depuis les tableaux `eras`, `events` et `points` du dataset). Le contrôle `count` vérifie `buttons.length === countries.length` et expose `data-m32-count`.
- **Impact** : les compteurs sont falsifiables depuis le panneau, sans ouvrir la fiche pays.
- **Risque** : le total global `meta.events` n'est pas recalculé ici (hors périmètre du contexte) ; M32 ne l'affirme donc jamais comme sien.
- **Effort** : M
- **Vérification** : relecture — 10 lignes, `data-m32-count="ok"`, valeurs È/R/P conformes au dataset.

## M32-10 — Idempotence multi-rendus et annonce maîtrisée

- **Titre** : le greffon est réappliqué à chaque émission du store.
- **Preuve** : `registry.js:17-19` conserve les tableaux de rappels, `:45-56` appelle tous les greffons à chaque `runMondeEnhancements` ; `globe.js:427` puis `:442` montrent la reconstruction du `stage` avant l'application.
- **Solution** : ID unique `#monde-m32-panel`, garde `isConnected` et `dataset.monde`, CSS unique via `ctx.css('monde-m32', ...)`, aucun écouteur sur un nœud partagé, aucun état conservé en dehors des constantes. Le seul écouteur (`toggle`) est posé sur le panneau possédé et appelle `ctx.say` uniquement à l'ouverture explicite ; `refresh()` relit le DOM à chaque passage.
- **Impact** : aucun doublon de panneau, aucune fuite d'écouteur, aucune annonce live parasite pendant le survol.
- **Risque** : un panneau déjà présent mais détaché est recréé ; la garde `isConnected` couvre ce cas. Le `say` est protégé par un test de type.
- **Effort** : M
- **Vérification** : `node --check src/views/monde/M32.js` PASS ; absence de `console.*`, `Math.random`, `fetch` et URL distante dans le module.

## Statut d'implémentation

Les 10 chantiers M32-01 à M32-10 sont implémentés dans `src/views/monde/M32.js`
uniquement. Le panneau `#monde-m32-panel` est injecté dans `ctx.scene`, ancré en
haut à droite sous le readout du HUD (`styles.css:130-137`) et à l'opposé des
commandes (`styles.css:150-152`) et de la légende M17. Aucun fichier partagé,
aucun sélecteur de test modifié, aucune donnée inventée.

Contrôles exposés sur le panneau : `data-m32-graphy`, `data-m32-title`,
`data-m32-accessible`, `data-m32-order`, `data-m32-unique`, `data-m32-text-only`,
`data-m32-labels`, `data-m32-count`, `data-m32-rows`, `data-m32-divergences`.

## Blocages

Le désalignement `id: "uk"` / `code: "GB"` (`dataset.js:9306-9310`) ne peut être
corrigé : le dataset est en lecture seule pour cette lentille. Il est documenté
dans le verdict et compté à part des 8 contrôles de conformité. La casse
`text-transform:uppercase` de `#globe-reveal .gr-caption` (`globe-reveal.js:82-83`)
reste sous la responsabilité de M17, qui la neutralise déjà.
