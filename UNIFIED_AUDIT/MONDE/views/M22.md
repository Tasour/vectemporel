# M22 — Ordre de lecture et continuité du focus (domaine C : ergonomie et interaction)

Lentille : M22. Fichier possédé : `src/views/monde/M22.js`.
Lectures seules : `src/views/globe.js`, `src/views/monde/registry.js`, `src/views/monde/index.js`, `styles.css`, `tests/e2e.mjs`, `UNIFIED_AUDIT/MONDE/README.md`.
Aucun fichier partagé modifié, aucun réseau, aucun aléa, aucun timer, aucune boucle rAF, aucun observateur, aucun message de journalisation.

**Périmètre.** La vue Monde construit une scène WebGL (`#globe-canvas`, `tabindex="0"`, globe.js:274-278) puis un HUD (statut, lecture, commandes), puis le panneau de décision (`.globe-list` avec `h1#globe-title`, `.globe-orientation`, `ol#globe-choices`, `.globe-help`). Le DOM est : scène → HUD → contrôles → liste (globe.js:317-440), alors que la grille CSS place la scène à gauche et la liste à droite (styles.css:119-126) : l'ordre de lecture et l'ordre visuel coïncident, mais le **premier tab stop est le canvas**, avant même le titre. La lentille ne réordonne ni `.globe-list` ni `.globe-country` (consigne du sous-agent) : elle n'ajoute aucun enfant dans ces deux sous-arbres et ne modifie que des attributs ou des nœuds de la scène et de l'hôte.

---

## M22-01 — Lien d'évitement en tête de scène : le premier Tab quitte le WebGL

- Preuve : `ensure()` pose `tabIndex = 0` sur `.globe-host` (globe.js:274) et `renderGlobe()` l'insert en premier enfant de `.globe-scene` (globe.js:319). Un lecteur d'écran ou un utilisateur clavier qui presse Tab atterrit donc directement sur la sphère, avant d'avoir entendu le titre « Choisir un pays » (globe.js:370).
- Solution : `#m22-skip-list`, ancre `.m22-skip` insérée par `scene.insertBefore(skip, scene.firstChild)`, hors de `.globe-list`. Masquée hors focus par `transform: translateY(-180%)` dans une scène en `overflow: hidden` (styles.css:127), elle devient visible au `:focus` avec `outline: 3px solid var(--gold-bright)`. Son clic appelle `focus()` sur `#globe-choices` au lieu de laisser l'ancrage natif défiler seulement.
- Impact : le premier point de tabulation est une commande de lecture explicite, pas un canvas opaque ; le titre de la vue reste le repère d'entrée.
- Risque : l'ancre est dans une scène `overflow: hidden` — hors focus elle est donc réellement invisible, mais un `z-index: 40` la garde au-dessus du HUD (`z-index: 4`) et des contrôles (`z-index: 5`) au moment du focus.
- Effort : S
- Vérification : `document.querySelector('.globe-scene').firstElementChild.id === 'm22-skip-list'` ; un Tab depuis le début du document donne le focus à `#m22-skip-list`, un second Tab au canvas.

## M22-02 — Cible de saut focalisable sans devenir un arrêt Tab

- Preuve : `#globe-choices` est un `<ol>` (globe.js:383-384), non focalisable par défaut ; une ancre `href="#…"` vers un élément non focalisable déplace le défilement mais pas toujours le focus (comportement historique des navigateurs).
- Solution : `prepareChoiceTarget()` pose `tabindex="-1"` sur `#globe-choices` (uniquement si absent) ; le clic du M22-01 appelle alors `choices.focus({ preventScroll: false })`. Le gestionnaire `focusin` existant (globe.js:393) continue d'enregistrer `lastFocusIndex` sur les boutons, et `onChoicesKeyDown` (globe.js:238) parcourt toujours les `button` : aucun conflit.
- Impact : saut fiable vers la grille, sans insérer de dixième arrêt Tab parasite dans la séquence.
- Risque : un autre greffon pourrait mettre `tabindex="0"` sur la liste ; la garde `!== -1` rétablit `-1` à chaque rendu, ce qui est le comportement voulu (la grille a déjà son point d'entrée via M22-05).
- Effort : S
- Vérification : `#globe-choices.tabIndex === -1` ; après clic sur `#m22-skip-list`, `document.activeElement.id === 'globe-choices'`.

## M22-03 — Descriptif de l'ordre de lecture adjoint à l'hôte du globe

- Preuve : `ensure()` attache déjà `aria-describedby="globe-help"` au canvas (globe.js:278) ; cette description parle des flèches et d'Échap, mais pas de la séquence Tab complète (globe → contrôles → liste → pays).
- Solution : nœud sr-only `#m22-order-help` appendu à `.globe-host` (jamais à `.globe-list`), puis son id **ajouté** à la liste existante de `aria-describedby` par tokenisation `/\s+/`, sans écraser `globe-help`. Texte : « Ordre de lecture … Tab suit cet ordre ; les flèches parcourent les pays ».
- Impact : un utilisateur de lecteur d'écran sait, dès le premier focus, combien de tabulations séparent le globe de la liste.
- Risque : l'ajout d'un second `aria-describedby` allonge l'annonce ; le texte est volontairement court (une phrase) pour ne pas noyer `globe-help`.
- Effort : S
- Vérification : `globe-canvas.getAttribute('aria-describedby').split(/\s+/)` contient exactement `globe-help` et `m22-order-help`, sans doublon après trois rendus.

## M22-04 — La liste devient une région nommée, jalon du fil de lecture

- Preuve : `.globe-list` est un simple `<div>` (globe.js:369) ; la navigation par landmarks d'un lecteur d'écran ne peut donc pas l'atteindre directement, alors qu'elle contient l'unique `h1` de la vue (globe.js:370).
- Solution : `nameRegions()` pose `role="region"` et `aria-labelledby="globe-title"` sur `.globe-list`, sous garde `hasAttribute` (attributs seuls, aucun enfant ajouté, aucun sélecteur de test modifié).
- Impact : la liste est un repère nommé « Choisir un pays », reachable par navigation de régions comme par le lien d'évitement du M22-01.
- Risque : si une autre lentille pose déjà `aria-labelledby`, la garde évite d'écraser son choix ; le titre `#globe-title` reste la source unique du nom.
- Effort : S
- Vérification : `.globe-list.getAttribute('role') === 'region'` et `.globe-list.getAttribute('aria-labelledby') === 'globe-title'`.

## M22-05 — Un seul point de tabulation dans la grille de dix pays

- Preuve : globe.js:403 pose `tabIndex = index === selected ? 0 : -1` (roving tabindex). Ce calcul est correct au rendu, mais toute mutation de `aria-current` par une autre lentille, ou un rendu partiel, peut laisser zéro ou plusieurs boutons tabulables et briser la continuité du focus.
- Solution : `normalizeCountryStops()` élit le bouton `aria-current="true"`, sinon l'éventuel `tabindex="0"`, sinon le premier, et force `0`/`-1` sur les dix `.globe-country`. Attributs seuls ; le parcours flèches de M25 n'est pas touché.
- Impact : Tab entre dans la grille par un seul point, puis ressort vers la suite du document en une seule pression.
- Risque : l'élection par `aria-current` suppose un seul pays courant (contrat C2 du globe) ; s'il y en a plusieurs, le premier l'emporte, ce qui reste déterministe.
- Effort : S
- Vérification : `document.querySelectorAll('.globe-country[tabindex="0"]').length === 1` ; l'élu porte `aria-current="true"` quand un pays est sélectionné.

## M22-06 — Ordre des contrôles : le HUD précède toujours les boutons

- Preuve : `renderGlobe()` ajoute `host` (319), puis `hud` (338), puis `controls` (364) ; `attachReveal()` peut cependant insérer `#globe-reveal` dans la scène et un greffon peut appendir un nœud après les contrôles, ce qui placerait un bouton avant le statut dans l'ordre de lecture.
- Solution : `orderControls()` vérifie que `.globe-controls` est le dernier enfant de `.globe-scene` et le ré-appendu sinon (`appendChild` d'un nœud existant, sans recréation, donc sans perte d'écouteurs). Le HUD `#globe-status` (role=status) et `#globe-hover-readout` restent avant.
- Impact : lecture stable « statut → mesure → commandes », indépendamment de l'ordre d'exécution des 50 greffons.
- Risque : ré-appendre un nœud pendant qu'il a le focus est sans danger pour le focus (le nœud reste le même), mais la garde `controls !== scene.lastElementChild` limite l'opération aux cas réels.
- Effort : S
- Vérification : dans `.globe-scene`, `lastElementChild.classList.contains('globe-controls')` est vrai ; `#globe-status` précède `#globe-hover-readout` dans `compareDocumentPosition`.

## M22-07 — Ordinal en tête du nom accessible des dix pays

- Preuve : `globe.js:397-399` masque le numéro `.globe-country-num` par `aria-hidden="true"`. Le lecteur d'écran entend donc « France, 3 ères … », mais pas « pays 3 sur 10 » : l'ordre énumératif de l'`<ol>` est perdu pour le nom du bouton.
- Solution : `labelCountries()` construit un `aria-label` — « Pays N sur total : nom. méta. couverture » — en lisant les nœuds existants, avec repli sur `countries[index].name`. Garde `hasAttribute('aria-label')` pour ne jamais écraser un libellé posé par M32/M41. Aucun enfant ajouté à `.globe-country`, aucun changement de `textContent`.
- Impact : l'ordre de lecture ordinal est restauré dans le nom accessible, et l'information de couverture n'est pas perdue.
- Risque : un `aria-label` masque le contenu interne aux lecteurs d'écran ; la solution réinjecte explicitement méta et couverture pour éviter toute régression d'information.
- Effort : M
- Vérification : le premier `.globe-country` a `aria-label` commençant par `Pays 1 sur 10 :` ; `textContent` contient toujours le nom du pays (contrôle E2E tests/e2e.mjs:25-29).

## M22-08 — Miroir déclaratif de la séquence de focus, sans instrumentation

- Preuve : `ctx` n'expose ni l'état du focus ni le moteur ; `getInfo()` ne donne que des compteurs de rendu (globe-engine.js:691-703). Un test E2E ne peut pas vérifier l'ordre Tab sans interroger le DOM.
- Solution : `refreshOrderMarker()` parcourt `.globe-view` avec `querySelectorAll('a[href], button')` et écrit sur l'hôte `data-m22-order` (séquence `1:… > 2:…`) et `data-m22-stops` (nombre). Recalculé à chaque rendu et au `onReady` du moteur.
- Impact : la séquence de lecture est auditable par simple lecture d'attribut, sans `console` ni instrumentation du routeur.
- Risque : les noms tronqués à 26 caractères sont un repère, pas une source de vérité ; le test doit comparer des ids (`m22-skip-list`, `globe-choices`) plutôt que des libellés.
- Effort : S
- Vérification : `globe-canvas.dataset.m22Stops === '14'` (1 lien d'évitement + 3 contrôles + 10 boutons pays) et `dataset.m22Order` commence par `1:m22-skip-list`.

## M22-09 — La vue entière porte le nom du titre

- Preuve : quand le focus arrive sur `#globe-canvas`, l'annonce porte l'aria-label du globe mais pas le contexte « vue Monde / Choisir un pays » fourni par `h1#globe-title` (globe.js:370), situé plus loin dans le DOM.
- Solution : `nameRegions()` pose `role="region"` (si absent) et `aria-labelledby="globe-title"` sur `.globe-view`, récupéré par `scene.closest('.globe-view')` sous garde `isConnected`.
- Impact : le contexte de la vue est annoncé dès l'entrée, sans déplacer le `h1` et sans en créer un second.
- Risque : une région englobant toute la vue est volontairement large ; elle ne remplace pas la région fine du M22-04, elle fournit le contexte au premier focus.
- Effort : S
- Vérification : `.globe-view.getAttribute('aria-labelledby') === 'globe-title'` et `document.querySelectorAll('h1').length === 1`.

## M22-10 — Idempotence : un seul jeu de nœuds M22 après n rendus

- Preuve : `runMondeEnhancements()` rejoue les 50 greffons à chaque rendu (globe.js:442, registry.js:51-57) et `readyCallbacks` s'accumule à chaque appel de `onReady` (registry.js:55).
- Solution : chaque nœud est cherché par id unique (`#m22-skip-list`, `#m22-order-help`) avant création ; le CSS passe par `ctx.css('monde-m22', …)` (cssOnce, registry.js:25-30) ; le callback `onReady` est enregistré une seule fois grâce à la garde module `readyHooked`. Les attributs sont posés sous garde `hasAttribute`, les listes d'ids sont tokenisées sans doublon.
- Impact : trois rendus successifs produisent exactement un lien d'évitement, un descriptif, une feuille de style et un callback ; aucune dérive du marqueur `data-m22-stops`.
- Risque : `document.getElementById` ne retrouve pas un nœud détaché d'un rendu précédent ; un nouveau nœud est alors créé dans le nouveau `.globe-view`, ce qui est correct puisque l'ancien n'est plus dans le document.
- Effort : S
- Vérification : après trois rendus, `document.querySelectorAll('#m22-skip-list').length === 1`, `document.querySelectorAll('#m22-order-help').length === 1`, `document.querySelectorAll('#monde-m22').length === 1` ; `mondeDiagnostics()` liste une seule entrée `M22` sans erreur.

## Statut d'implémentation

Les 10 chantiers sont implémentés dans `src/views/monde/M22.js`. Un seul fichier modifié, aucun fichier partagé touché. CSS injecté via `ctx.css('monde-m22', …)`, nœuds à ids uniques avec garde d'existence, un seul `onReady`, zéro timer, zéro rAF, zéro observateur, zéro réseau, zéro aléa, zéro message de journalisation. `node --check src/views/monde/M22.js` passe.

## Blocages

- Aucun bloquant. M22 ne peut pas déplacer le `h1#globe-title` avant le canvas sans modifier `globe.js` : le M22-01 (lien d'évitement) et le M22-09 (nom de région) compensent cette contrainte sans créer de second titre.
- Consigne respectée : aucun enfant n'est ajouté à `.globe-list` ni à `.globe-country` ; toutes les améliorations de ces zones passent par des attributs (`aria-labelledby`, `role`, `tabindex`, `aria-label`) réversibles et sans changement de structure.
