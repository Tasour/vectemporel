# M45 — Tests E2E du globe

Lentille M45 — domaine E : qualité & validation. Fichier possédé :
`src/views/monde/M45.js`. Lectures seules : `tests/e2e.mjs`, `scripts/verify.mjs`,
`src/views/globe.js`, `src/views/monde/registry.js`, `src/ui/shell.js`, `src/app.js`,
`UNIFIED_AUDIT/MONDE/README.md`. Aucun test modifié, aucun navigateur piloté,
aucune touche ni clic synthétisé, aucun fichier partagé touché, zéro réseau,
zéro `Math.random`, zéro `console.*`.

Rôle : la lentille ne *rejoue* pas Puppeteer — elle **reflète** son contrat.
Les 16 contrôles de `tests/e2e.mjs:23-62` sont encodés dans l'ordre (`E2E`) et
évalués passivement sur le DOM courant et `window.VATLAS.getState()`. Le résultat
est déposé dans `#monde-m45-contract` et sur les attributs `data-m45-*`, donc
auditable sans produire une seule ligne de console. Les quatre contrôles
statiques emblématiques de `scripts/verify.mjs` sont mirrorés dans `STATIC`.

## M45-01 — Contrat E2E absent de l'application

- **Problème** : les 16 assertions ne vivent que dans le fichier de test ; une régression du globe n'est visible qu'au prochain `npm run test:e2e`, sans trace dans l'app elle-même.
- **Preuve** : `tests/e2e.mjs:7-10` — `check()` fait uniquement `console.log(PASS/FAIL …)` et incrémente `failed` ; `:64` affiche le bilan en console. `scripts/verify.mjs:11-14` idem. Aucun nœud du DOM ni attribut ne porte ce contrat.
- **Solution** : table `E2E` figée dans l'ordre exact du test, panneau `#monde-m45-contract` (`role=group`, `<table>` détaillé sr-only + badge visible) et miroir `data-m45-checks/-pass/-fail/-pending/-signature` sur le host.
- **Impact** : l'état du contrat est lisible dans le DOM à chaque rendu, sans ouvrir la console ni modifier le test.
- **Effort** : M
- **Vérification** : `node --check src/views/monde/M45.js` ; relecture — `E2E` contient 16 entrées et `data-m45-signature` est alimenté.

## M45-02 — Contrôle d'entrée « accueil = globe » figé trop tard

- **Problème** : le greffon n'est appliqué que sur la vue Monde (`globe.js:433-442`) ; s'il lisait l'état courant à chaque appel, il écraserait le constat d'entrée par la vue courante après une navigation.
- **Preuve** : `tests/e2e.mjs:23` vérifie l'état initial avant tout clic ; `app.js` expose `window.VATLAS.getState()` ; `shell.js:529-563` reconstruit tout le DOM à chaque changement d'état.
- **Solution** : `firstView` est capturé une seule fois, au premier `register()` (`if (firstView === null)`), comparé à `globe` et figé dans `results.accueil` puis `data-m45-accueil`. Aucune réécriture ensuite.
- **Impact** : l'entrée par défaut est certifiée par un instantané immuable, fidèle à la première assertion du test.
- **Effort** : S
- **Vérification** : relecture — une seule assignation de `firstView`, `data-m45-accueil`=vide avant le premier rendu puis `globe`.

## M45-03 — « 10 pays listés » : compter sans altérer le sélecteur de test

- **Problème** : le test compte les boutons de `.globe-list` ; la lentille ne doit ni en ajouter, ni en retirer, ni renommer une classe.
- **Preuve** : `tests/e2e.mjs:24-25` — `(await page.$$('.globe-list button')).length === 10` ; `UNIFIED_AUDIT/MONDE/README.md:56` interdit de modifier les sélecteurs de test ; `globe.js:369,383-424` construit la liste.
- **Solution** : lecture seule de `count(stage, '.globe-list button')`, comparée à `ctx.countries.length` (10), exposée dans `results.pays`. Le panneau M45 vit dans `scene`, hors de `.globe-list`, et ne contient aucun bouton.
- **Impact** : le compteur est vérifié sans modifier la cible de l'assertion ; le test reste rejouable à l'identique.
- **Effort** : S
- **Vérification** : relecture — aucun `classList`, aucun `appendChild` dans `.globe-list` ; `data-m45-pass` reflète 16 contrôles.

## M45-04 — « pays → chronologie » : observer la transition sans clic synthétique

- **Problème** : `e2e.mjs:31-33` clique sur France puis vérifie `view === chronology && countryId`. Une lentille qui cliquerait elle-même perturberait le test réel.
- **Preuve** : `globe.js:415-417` — le clic Événement appelle `selectCountry(country.id)` ; `app.js` publie `openCountry` et `getState` ; `shell.js:533` remplace `root.innerHTML` à chaque rendu.
- **Solution** : un unique `MutationObserver` sur `document.body` (`childList`, `subtree`) déclenche une réévaluation coalescée ; lorsque l'état public porte `view === chronology` et un `countryId`, `results.chrono` passe à `ok`. Aucun `click()`, aucun `dispatchEvent()`.
- **Impact** : la transition est constatée exactement comme le test la constate, sans effets de bord sur le parcours utilisateur.
- **Effort** : M
- **Vérification** : relecture — une seule `new MutationObserver`, aucun `click`/`dispatchEvent` ; `data-m45-signature` évolue après navigation.

## M45-05 — « repères affichés » et « flèche change de repère »

- **Problème** : deux assertions dépendent du contexte Chronologie et d'un index précis ; les évaluer hors contexte produirait un faux FAIL.
- **Preuve** : `tests/e2e.mjs:34` — `.event-card` non vide ; `:35-37` — après `ArrowRight`, `eventIndex === 1` ; `globe.js` délègue la flèche au routeur unique.
- **Solution** : dans `evaluate()`, `results.reperes` n'est posé que si `count(stage, '.event-card') > 0` en vue Chronologie ; `results.fleche` n'est posé que si `s.eventIndex === 1`. Sinon le résultat reste collant (`wait` puis éventuellement `ok`), jamais `ko` par défaut.
- **Impact** : le miroir distingue « non encore observé » de « échec observé », comme le fait le test séquentiel.
- **Effort** : S
- **Vérification** : relecture — `statusOf()` ne renvoie `wait` que tant qu'aucune évaluation n'a eu lieu ; relecture des deux gardes `view === 'chronology'`.

## M45-06 — « Entrée ouvre / Échap ferme le détail » sans envoyer de touches

- **Problème** : le test vérifie l'apparition puis la disparition de `.detail-sheet` ; la lentille ne doit pas presser Entrée ni Échap à sa place.
- **Preuve** : `tests/e2e.mjs:38-43` — `.detail-sheet` passe de 0 à 1 puis à 0 ; `globe.js:226-227` laisse Échap au routeur unique ; `shell.js:557-561` monte la feuille de détail.
- **Solution** : comptage passif de `.detail-sheet` dans `document`. À `1`, on mémorise `sawDetail` et on valide `ouvrir` ; au retour à `0` avec `sawDetail`, on valide `fermer`. Le drapeau rend l'observation de la fermeture falsifiable.
- **Impact** : l'ouverture et la fermeture sont toutes deux constatées, y compris si la fermeture survient après plusieurs rendus.
- **Effort** : S
- **Vérification** : relecture — `sawDetail` n'est posé que sur présence du sélecteur de test ; aucun `KeyboardEvent` synthétique dans le module.

## M45-07 — Raccourcis 3/4/5/6/1 et contrôles de contenu associés

- **Problème** : six assertions du test portent sur le changement de vue par touche, deux sur la présence d'un repère de contenu ; un miroir partiel laisserait le contrat incomplet.
- **Preuve** : `tests/e2e.mjs:44-61` — touches `3` (récit), `4` (géo), `5` (constellation), `6` (points), `1` (globe) ; `:47` — `.recit-title` unique ; `:51` — `.geo-marker` présent.
- **Solution** : `evaluate()` lit `s.view` pour `recit`, `geo`, `constellation`, `points` et `retour` (avec `leftGlobe` pour prouver le retour). `.recit-title` est compté à 1 et `.geo-marker` à strictement plus de 0, uniquement dans leur vue respective.
- **Impact** : la table `E2E` reflète la totalité du parcours clavier du test, pas seulement l'entrée et la sortie.
- **Effort** : M
- **Vérification** : relecture — les cinq clés de vue et les deux clés de contenu sont alimentées dans `evaluate()`.

## M45-08 — « orbites figées » : vérifier l'absence d'animation en lecture seule

- **Problème** : le test interdit tout style d'animation inline dans `.constellation-field`. Une lentille qui injecterait un `style` animé, même ailleurs, fausserait le contrat.
- **Preuve** : `tests/e2e.mjs:58` — `!document.querySelector('.constellation-field')?.querySelector('[style*="animation"]')` ; `constellation.js:138` — `.constellation-field * { animation: none !important }`.
- **Solution** : `results.orbites = count(document, '.constellation-field [style*="animation"]') === 0`. L'absence de champ vaut PASS, exactement comme l'option chaining du test. La feuille M45 n'écrit aucun style inline et n'ajoute aucune animation CSS.
- **Impact** : le contrôle anti-animation est reflété sans jamais introduire l'effet qu'il proscrit.
- **Effort** : S
- **Vérification** : relecture — aucun `style=` sur les nœuds créés, aucune règle `animation` dans la feuille `monde-m45`.

## M45-09 — Contrôles statiques : 10 pays, 229 repères, zéro lien externe

- **Problème** : `scripts/verify.mjs` porte des invariants que le test navigateur ne rejoue pas ; une dérive du dataset ou de l'interface resterait invisible depuis le globe.
- **Preuve** : `scripts/verify.mjs:16` (10 pays), `:18` (229 repères), `:25` (aucun Grokipedia), `:26` (aucun lien externe dans l'interface) ; `dataset.js:3-14` publie `meta.countries=10` et `meta.events=229`.
- **Solution** : table `STATIC` de quatre entrées évaluées depuis `window.VATLAS.meta`, `ctx.countries` et le DOM : présence d'un `href` http/protocole-relatif, et recherche de Grokipedia dans `textContent`. Résultat agrégé dans `data-m45-static` sous forme `1111` / `0` / `-`.
- **Impact** : les invariants de la vérification statique sont visibles dans le même miroir que les contrôles E2E.
- **Effort** : M
- **Vérification** : relecture — `meta.events === 229`, `total === 10`, sélecteur d'ancrage `a[href^="http"]` ; `node --check` PASS.

## M45-10 — « aucune erreur console » : silence de la lentille et budget de sonde

- **Problème** : le test échoue sur la moindre erreur console (`e2e.mjs:18-19,62`) ; le miroir lui-même ne doit ni écrire dans la console, ni fuir des écouteurs, ni s'auto-réexciter.
- **Preuve** : `registry.js:45-56` réapplique les greffons à chaque rendu et :50-52 accumule les callbacks ; `MONDE/README.md:57` exige zéro `console.*` ; `e2e.mjs:62` exige zéro erreur.
- **Solution** : capture passive `error`/`unhandledrejection` en `errorCount` (jamais de `console.log`), écouteurs et observer installés une seule fois (`installed`). `refresh()` coalesce par un seul `requestAnimationFrame`, coupe la sonde pendant ses propres écritures (`disconnect()`/`observe()`) pour éviter la boucle, et ne pose aucun timer, aucun `Math.random`, aucune requête réseau. Toutes les fonctions sensibles sont enveloppées de `try/catch` silencieux.
- **Impact** : contrôle 16 validé sans bruit, idempotence sur rendus répétés, surcoût borné à un rAF par salve de mutations et aucun sélecteur de test modifié.
- **Effort** : M
- **Vérification** : `node --check` PASS ; recherche texte — aucune occurrence de `console.`, `fetch`, `XMLHttpRequest`, `Math.random`, `setTimeout`, `setInterval`, `@import` ou `url(http` dans `M45.js`.
