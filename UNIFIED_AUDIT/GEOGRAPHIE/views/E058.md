# Lentille E058 — Minicarte / aperçu global

- Vue : GEOGRAPHIE (`src/views/geography.js`)
- Module possédé : `src/views/geography/E058.js`
- Contrat : `register('E058', ctx => { … })` avec `ctx = { viewId, stage, layout, css, el, reducedMotion() }`

## Thème

Offrir un aperçu global permanent de la carte : une minicarte qui montre tout le domaine connu et le rectangle de la vue courante. La lentille enrichit la vue GEOGRAPHIE d'un panneau pédagogique autonome — un laboratoire canvas unique, un rectangle de vue calculé depuis le `viewBox` réel, des repères projetés depuis les marqueurs existants, un tableau sémantique, des mesures chiffrées référencées, une graticule, un balayage animé et une navigation clavier. Un clic sur l'aperçu rejoint le repère documenté le plus proche via le vrai gestionnaire du marqueur, sans réimplémenter la projection et sans déplacer fictivement un lieu. Tout est local, en français, sans réseau, sans aléa et sans journalisation.

## Diagnostic

La vue GEOGRAPHIE affiche une carte zoomable dont le `viewBox` peut être réduit jusqu'au huitième du domaine. Plus le zoom est fort, plus le contexte environnant disparaît : rien ne montre où la vue se situe dans l'ensemble, ni quels repères existent hors cadre. E058 comble ce vide sans toucher au fichier de vue : le panneau est inséré dans `.geo-panel`, le badge d'aperçu dans `#c3b-map`, et le contenu pédagogique reste du texte sémantique lisible même sans interaction. L'aperçu réutilise le repère de la carte principale (`MAP_W = 900`, `MAP_H = 620`) : le rectangle de vue est donc directement lisible dans les coordonnées du `viewBox`.

## Les 10 chantiers

### E058-01 — Panneau sémantique et CSS isolé — Implémenté

`ctx.css('geography-e058', …)` injecte un bloc unique, préfixé, sans ressource externe (replis `var(--…, …)` et media queries). Le panneau `section#geography-e058-panel` porte un titre `h2`, un chapô et trois faits sourcés en paragraphes `.geography-e058-fait` : l'ensemble est du texte DOM, lisible sans JavaScript. Le panneau est idempotent : il n'est reconstruit que s'il n'est plus connecté.

### E058-02 — Aperçu global dans le repère de la carte — Implémenté

Le domaine de l'aperçu est exactement celui du `viewBox` de la carte (`0…900 × 0…620`). `viewGeom()` calcule une transformation conforme (`scale` unique, centrage, marge), `toPx()` et `toOv()` assurent les allers-retours coordonnées aperçu ↔ pixels CSS. Le contour du pays est lu dans `polygon.geo-outline` du SVG principal puis ramené à l'aperçu : aucune géométrie n'est inventée.

### E058-03 — Rectangle de vue calculé depuis le viewBox — Implémenté

`currentBox()` lit l'attribut `viewBox` réel de `.geo-svg` (avec repli vue entière). Le rectangle est tracé en trait blanc tireté aux coordonnées `(x, y, w, h)` ainsi obtenues, avec un libellé `vue ×facteur`. Il se met à jour à chaque rendu : agrandir ou réduire la vue principale modifie immédiatement l'aperçu. Les repères se distinguent par la forme — losange pour le lieu actif, cercle plein dans le cadre, cercle tireté hors cadre — jamais par la seule couleur.

### E058-04 — Tableau sémantique des repères — Implémenté

Un `<table id="geography-e058-table">` liste, pour chaque marqueur de la carte, son libellé, ses coordonnées x et y et sa présence dans le cadre courant (`Oui` / `Non`). Le `caption` précise le repère de coordonnées ; les en-têtes portent `scope="col"` et `scope="row"`. Le corps est reconstruit à chaque synchronisation depuis les marqueurs réels, avec un message explicite si la liste est vide.

### E058-05 — Laboratoire canvas unique — Implémenté

Un seul `<canvas id="geography-e058-canvas">` dessine le cadre de l'aperçu, le contour du pays, les repères, le rectangle de vue, le curseur clavier et la ligne de balayage. Le dimensionnement respecte `DPR ≤ 2`, le contexte 2D est réinitialisé proprement à chaque frame et la géométrie est factorisée. Le canvas n'est qu'un laboratoire : toutes les informations sont aussi dans le DOM (tableau, légende, statut).

### E058-06 — Navigation par clic sur l'aperçu — Implémenté

Un clic convertit la position du pointeur en coordonnées aperçu via `toOv()`, puis `selectNearest()` identifie le repère documenté le plus proche et appelle `.click()` sur le vrai groupe `.geo-marker`. Le gestionnaire natif de la carte sélectionne alors le lieu — aucun déplacement fictif, aucune réimplémentation de la projection. Le résultat est annoncé dans la région de statut avec les coordonnées du repère rejoint.

### E058-07 — Mesures chiffrées référencées — Implémenté

Le `readout` (`role="status" aria-live="polite"`) affiche trois grandeurs recalculées depuis la géométrie courante : la couverture du domaine en pourcentage `(w × h) / (900 × 620)`, le facteur de zoom `900 / w` comparé à la référence `×1,00` de la vue entière, et le nombre de repères dans le cadre sur le total. Les valeurs sont formatées avec une virgule décimale et mises à jour à chaque changement de vue.

### E058-08 — Bascules indépendantes et motifs distincts — Implémenté

Deux cases indépendantes (« Tous les repères », « Graticule ») pilotent l'affichage : la première montre les repères hors cadre en cercles tiretés, la seconde affiche une graticule tous les 150 unités. La légende `#geography-e058-legend` nomme chaque motif (losange, cercle plein, cercle tireté, croix, rectangle tireté) : l'information ne repose jamais sur la seule couleur. Les cibles sont d'au moins 36 px.

### E058-09 — Balayage animé, rAF unique — Implémenté

Une seule boucle `requestAnimationFrame` (`startSweep` → `tickSweep` → reprogrammation, annulée par `stopSweep`) fait parcourir l'aperçu à une ligne verticale en huit secondes, sans aléa. Le temps ne progresse pas quand `document.hidden` est vrai : `visibilitychange` arrête ou relance la boucle, et `tickSweep` se protège également. Le bouton `#geography-e058-sweep` porte `aria-pressed` ; avec `ctx.reducedMotion()`, le balayage est affiché à son terme en une seule frame, sans boucle.

### E058-10 — Clavier, recentrage réel et badge — Implémenté

Le canvas est focalisable (`tabindex="0"`) avec un `aria-label` unique : flèches pour déplacer le curseur (pas de 30 unités, 90 avec Maj), `Entrée` pour rejoindre le repère le plus proche, `R` pour restaurer la vue entière via le vrai bouton `data-fk="c3b-zoom-reset"`, `G` pour basculer la graticule. Le bouton `#geography-e058-reset` offre le même recentrage. Chaque action est annoncée dans `#geography-e058-status`. Un badge `#geography-e058-badge` est posé sur `#c3b-map` pour rappeler que l'aperçu est schématique et sans réseau.

## Contraintes respectées

- Un seul module modifié ; aucun stub ; les dix chantiers sont actifs.
- `ctx.css('geography-e058', …)`, tous les identifiants préfixés `geography-e058-*` ; un seul `register('E058', …)`.
- Zéro journalisation, zéro appel réseau, zéro `Math.random()` ; le mot « console » n'apparaît nulle part.
- Une seule boucle rAF, suspendue sur `document.hidden` ; un seul canvas dessiné par frame.
- État de module conservé entre les rendus ; panneau et badge idempotents.
- Contenu textuel sémantique, lisible sans JavaScript ; français intégral.
- Accessibilité : cibles tactiles ≥ 36 px (44 px pour les boutons), focus visible, `aria-pressed` réservé aux deux bascules indépendantes, `role="status" aria-live="polite"`, équivalents clavier complets, information jamais portée par la seule couleur.
- Aucune modification de la vue ni d'un fichier partagé ; la projection et la sélection restent celles de `geography.js`.
