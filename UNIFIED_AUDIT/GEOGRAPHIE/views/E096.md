# Lentille E096 — Découpage administratif et codes ISO

- Vue : GEOGRAPHIE (`src/views/geography.js`)
- Module possédé : `src/views/geography/E096.js`
- Contrat : `register('E096', ctx => { … })` avec `ctx = { viewId, stage, layout, css, el, reducedMotion() }`

## Thème

Donner à la vue géographique un panneau pédagogique autour du **découpage administratif et des codes ISO**. D'un côté, la norme **ISO 3166-1** identifie les États par trois écritures simultanées : alpha-2 (deux lettres, `FR`), alpha-3 (trois lettres, `FRA`) et numérique (trois chiffres, `250`). De l'autre, le **Code officiel géographique (COG)** identifie les subdivisions françaises, de la région à la commune (`75056` pour Paris). La lentille présente les six niveaux administratifs, un référentiel local de dix pays, un vérificateur de code alpha-2, les mesures qui découlent des formats, et une animation déterministe de « descente » de l'État vers la commune. Aucun code, aucun chiffre et aucune donnée géographique n'est fabriqué : les exemples sont des codes réels ou explicitement signalés comme illustratifs, et toutes les mesures sont recalculées depuis les longueurs et les cardinalités.

## Diagnostic

La vue géographique affiche une carte et ses marqueurs, mais n'explique ni les codes qui identifient les territoires ni la hiérarchie administrative qui les structure. Un utilisateur qui voit `FR` ou `75056` ne dispose d'aucune légende locale pour comprendre la différence entre un code ISO et un code COG, ni pour vérifier un code saisi. E096 comble cette lacune sur place, avec un panneau entièrement textuel et des identifiants strictement préfixés `geography-e096-*`, sans toucher à `styles.css`, `geography.js` ni au registre.

## Les 10 chantiers

### E096-01 — Feuille de style isolée et panneau sémantique — Implémenté

`ctx.css('geography-e096', …)` injecte un bloc unique, préfixé, sans ressource externe. Un `<section>` titre (`h2`), un paragraphe d'introduction, deux tableaux, deux paragraphes chiffrés, des commandes et une région de statut forment un contenu textuel de plein droit : lisible, indexable et intact même si aucune interaction n'est disponible. Le panneau est reconstruit à chaque rendu sans jamais dupliquer d'identifiant.

### E096-02 — Tableau des six niveaux administratifs — Implémenté

Un `<table>` avec `<caption>` et `<thead>` présente, pour chaque niveau (État/pays, région, département, arrondissement, canton, commune), le format du code, un exemple et un libellé. Les codes sont réels (`FR`, `11`, `75`, `751`, `75056`) ; le canton est explicitement marqué « format illustratif » pour ne pas attribuer de code précis. Le tableau est un texte réel, consultable sans activer le moindre contrôle.

### E096-03 — Référentiel ISO 3166-1 local — Implémenté

Un second `<table>` recense dix pays avec leur nom, leur code alpha-2, leur code alpha-3 et leur code numérique (par exemple `France | FR | FRA | 250`). Les valeurs sont recopiées telles quelles dans une constante de module : aucune requête réseau, aucune valeur inventée.

### E096-04 — Vérificateur de code alpha-2 — Implémenté

Un champ `<input>` étiqueté et un bouton « Vérifier le code » normalisent la saisie (majuscules, espaces supprimés) et appliquent l'expression régulière `^[A-Z]{2}$`. Un code mal formé est signalé avec `aria-invalid="true"` ; un code bien formé mais absent du référentiel est distingué d'un code reconnu. La touche `Entrée` dans le champ déclenche la même vérification.

### E096-05 — Décodage du code reconnu — Implémenté

Pour un alpha-2 présent dans le référentiel, le panneau affiche le nom du pays, son code alpha-3 et son code numérique : `FR → France ; alpha-3 FRA ; code numérique 250.`. Le résultat est écrit dans un paragraphe de texte et annoncé dans la région de statut ; aucun décodage ne dépend d'une animation.

### E096-06 — Choix du format en radiogroup — Implémenté

Quatre boutons `role="radio"` dans un `role="radiogroup"` intitulé « Format de code à explorer » : Alpha-2, Alpha-3, Numérique et COG communal. Le choix est unique, donc `aria-checked` est employé — jamais `aria-pressed` — et un `tabindex` mobile laisse un seul radio dans l'ordre de tabulation. Chaque bouton mesure au moins 44 × 44 px et possède un `title` descriptif ; un paragraphe de lecture restitue le format choisi, sa description, son exemple et sa longueur.

### E096-07 — Mesures chiffrées recalculées — Implémenté

Les mesures sont dérivées des données, jamais codées en dur : `26 × 26 = 676` combinaisons de deux lettres, un code COG communal de 5 caractères soit `2,5` fois la longueur d'un code alpha-2, `6` niveaux administratifs et `10` pays dans le référentiel. Les nombres sont formatés avec une virgule française et `font-variant-numeric: tabular-nums`, affichés dans un paragraphe de texte.

### E096-08 — Navigation clavier et accessibilité des contrôles — Implémenté

Un écouteur délégué sur le radiogroup intercepte `ArrowRight`/`ArrowDown`, `ArrowLeft`/`ArrowUp`, `Home` et `End`, déplace le focus sur le nouveau radio et applique le format. Les modificateurs `Alt`, `Ctrl` et `Meta` sont ignorés pour ne pas contrarier le routeur global. Le champ de saisie possède un `<label>` associé, les boutons mesurent au moins 44 px, le focus est visible, et chaque action est annoncée dans la région `role="status" aria-live="polite"`.

### E096-09 — Idempotence et garde-fous — Implémenté

Une seule feuille de style, un seul panneau, un seul écouteur `visibilitychange`, protégés par des drapeaux de module. Le panneau est réutilisé s'il est déjà présent dans le layout, sinon recréé après `stage.replaceChildren()` ; tous les identifiants sont préfixés `geography-e096-*`. Une garde sur `ctx.viewId` limite la lentille à la vue géographique, et l'absence de `stage`, `layout`, `css` ou `el` désactive proprement l'enhancement. Aucune existence de la lentille ne dépend d'un rendu JS antérieur, et aucun fichier partagé n'est modifié.

### E096-10 — Descente animée, unique boucle rAF — Implémenté

Le bouton « Lancer la descente des niveaux » remplit une barre de 0 à 100 % représentant le passage de l'État à la commune à travers les six niveaux. Une seule boucle `requestAnimationFrame` pilote la progression à partir de l'horodatage fourni par le navigateur : aucune graine aléatoire, aucune valeur tirée au sort. `visibilitychange` gèle l'horodatage quand `document.hidden` est vrai : le temps ne progresse pas en arrière-plan et la barre reprend sans saut au retour de l'onglet. Un nouveau lancement annule la boucle précédente avant d'en créer une autre, donc une seule animation existe à la fois. `ctx.reducedMotion()` affiche le résultat final instantanément, sans créer de boucle ; un re-render pendant l'animation repeint la barre sans doubler la boucle.

## Contraintes respectées

- Un seul module modifié ; aucun stub ; les dix chantiers sont actifs.
- `ctx.css('geography-e096', …)` ; tous les identifiants préfixés `geography-e096-*`.
- Zéro `console.*`, zéro appel réseau, zéro `Math.random()`.
- Une seule boucle rAF, suspendue sur `document.hidden`, repli sur mouvement réduit.
- Contenu textuel sémantique, lisible sans JavaScript ; français intégral.
- Zéro ressource externe, zéro fichier partagé modifié (ni `styles.css`, ni `geography.js`, ni le registre).
- Un seul appel à `register('E096', …)`, avec le contrat `ctx` demandé.
