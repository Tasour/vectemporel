# Lentille E039 — Cartographie historique et évolution des contours

- Vue : GEOGRAPHIE (`src/views/geography.js`)
- Module possédé : `src/views/geography/E039.js`
- Contrat : `register('E039', ctx => { … })` avec `ctx = { viewId, stage, layout, css, el, reducedMotion() }`

## Thème

Montrer comment le tracé d'un même territoire évolue selon l'époque cartographiée, et en quoi une carte historique diffère d'une carte actuelle. La lentille enrichit la vue GEOGRAPHIE d'un panneau pédagogique autonome : quatre contours schématiques (Antiquité → époque contemporaine) interpolés sommet à sommet, des mesures recalculées à chaque instant, une surimposition par motifs de trait et un laboratoire canvas déterministe. Tout est local, en français, sans réseau, sans aléa et sans console.

## Diagnostic

La vue GEOGRAPHIE dessine un contour unique (`polygon.geo-outline`) figé sur l'ère courante et une légende textuelle statique. Rien ne permet de comparer deux tracés successifs, de voir un contour se déformer dans le temps, ni de rattacher une mesure à une époque de référence. E039 comble ce vide sans toucher au fichier de vue : le panneau est inséré dans `.geo-panel`, le badge schématique dans `.geo-map`, et le contenu pédagogique reste du texte sémantique lisible même sans interaction.

## Les 10 chantiers

### E039-01 — Panneau sémantique et CSS isolé — Implémenté

`ctx.css('geography-e039', …)` injecte un bloc unique, préfixé, sans ressource externe (avec replis `var(--…, …)` et media queries). Le panneau `section#geography-e039-panel` porte un titre `h2`, un chapô et trois faits sourcés en paragraphes `.geography-e039-fait` : l'ensemble est du texte DOM, lisible sans JavaScript.

### E039-02 — Quatre époques canoniques — Implémenté

`ERAS` définit quatre époques (Antiquité, Moyen Âge, Époque moderne, Époque contemporaine), chacune avec `N = 12` rayons angulaires ordonnés. Le nombre de sommets identique permet une interpolation sommet à sommet entre deux époques quelconques. L'Antiquité sert de référence (`REF = 0`).

### E039-03 — Sélecteur d'époque (choix unique) — Implémenté

Un `fieldset` en radiogroupe (`name="geography-e039-epoque"`) propose les quatre époques. Chaque choix est une étiquette cliquable avec `input` d'au moins 18 px et cible d'au moins 36 px ; sélectionner une époque fixe la position `S.t` et resynchronise tout le panneau.

### E039-04 — Tableau et séquence sémantiques — Implémenté

Un `<table>` (`#geography-e039-table`) donne pour chaque époque la superficie, le périmètre et le rapport à la référence, avec `caption`, en-têtes `scope="col"`/`scope="row"` et valeurs calculées. Une liste ordonnée `#geography-e039-sequence` décrit en quatre étapes l'évolution morphologique du contour.

### E039-05 — Laboratoire canvas unique — Implémenté

Un seul `<canvas id="geography-e039-canvas">` trace la graticule et le contour courant. Le dimensionnement respecte `DPR ≤ 2`, le contexte 2D est réinitialisé proprement, et le tracé du contour est factorisé dans `traceContour`. Le canvas n'est qu'un laboratoire : toute l'information est aussi dans le DOM.

### E039-06 — Curseur de temps et morphing déterministe — Implémenté

Un `input[type=range]` continu (`#geography-e039-time`, de 0 à 3, pas de 0,01) pilote `S.t`. `contourPoints(t)` interpole linéairement les rayons des deux époques encadrantes : le contour se déforme de façon reproductible, sans aucune graine aléatoire.

### E039-07 — Mesures chiffrées référencées — Implémenté

`aire()` (formule du lacet) et `perimetre()` (distances consécutives) calculent les grandeurs depuis la géométrie courante. Le `readout` (`role="status" aria-live="polite"`) affiche superficie, périmètre et rapport en pourcentage à l'Antiquité prise pour référence (100 %). Trois grandeurs chiffrées, dont une comparée à une référence, recalculées à chaque changement.

### E039-08 — Surimposition par motifs de trait — Implémenté

Une case indépendante (`#geography-e039-overlay`) superpose les quatre contours avec des motifs de trait distincts (plein, tirets longs, points, tirets + points) et des teintes variées. La légende `#geography-e039-legend` nomme chaque motif : l'information ne repose jamais sur la seule couleur.

### E039-09 — Animation rAF unique — Implémenté

Une seule boucle `requestAnimationFrame` (démarrée par `startLoop`, reprogrammée dans `tick`, annulée par `stopLoop`) fait avancer la séquence en ~12 s. Le temps ne progresse pas quand `document.hidden` est vrai ; `visibilitychange` arrête ou relance la boucle. Le bouton `#geography-e039-play` porte `aria-pressed` ; avec `ctx.reducedMotion()`, l'animation devient un affichage instantané à la dernière époque.

### E039-10 — Clavier, réinitialisation et badge — Implémenté

Le canvas est focalisable (`tabindex`) avec un `aria-label` unique : flèches haut/bas pour changer d'époque, gauche/droite pour avancer par quarts, `S` pour la surimposition, `R` pour réinitialiser. Le bouton `#geography-e039-reset` ramène à l'Antiquité, sans surimposition, et annonce l'action dans le statut. Un badge schématique est posé sur `.geo-map` pour rappeler que les tracés sont pédagogiques.

## Contraintes respectées

- Un seul module modifié ; aucun stub ; les dix chantiers sont actifs.
- `ctx.css('geography-e039', …)`, tous les identifiants préfixés `geography-e039-*` ; un seul `register('E039', …)`.
- Zéro `console.*`, zéro appel réseau, zéro `Math.random()` ; le mot « console » n'apparaît que dans un commentaire.
- Une seule boucle rAF, suspendue sur `document.hidden` ; un seul canvas dessiné.
- État de module conservé entre les rendus ; panneau et badge idempotents.
- Contenu textuel sémantique, lisible sans JavaScript ; français intégral.
- Accessibilité : radiogroupe, cases indépendantes, cibles tactiles ≥ 36 px (44 px pour les boutons), focus visible, status annoncé, équivalents clavier.
