# Lentille E004 — Rose des vents et orientation cardinale

**Vue :** GEOGRAPHIE (`src/views/geography.js`) · **Module :** `src/views/geography/E004.js`
**Contrat :** `register('E004', (ctx) => { … })`, appliqué par `runEnhancements({ viewId, stage, layout })` en fin de rendu.

## Thème

Dotée la carte schématique locale d'une **rose des vents** et d'un vocabulaire d'**orientation cardinale** sans jamais inventer d'azimut. Le jeu de données fournit des latitudes, longitudes, un contour et des lieux ; il ne fournit ni déclinaison magnétique ni nord magnétique. La lentille exploite donc deux sources réelles et vérifiables :

1. la **projection** de `geography.js` : `y = (maxLat − lat) / Δlat × hauteur`, donc les latitudes croissantes vont vers le haut — le nord est en haut du cadre ;
2. le **viewBox** effectif du SVG et la position **réelle** du marqueur actif (`.geo-marker[aria-pressed="true"] .geo-ring`).

Le cap calculé est étiqueté « direction schématique dans le cadre », jamais « azimut géographique ». Toute l'information est portée par du texte dans le DOM ; le canvas n'est qu'un laboratoire qui ne détient aucune donnée exclusive.

## Les dix chantiers

| Chantier | Réalisation effective |
| --- | --- |
| **E004-01 — CSS isolé et portée** | Un unique `ctx.css('geography-e004', …)` dédupliqué par `cssOnce`. Toutes les règles sont préfixées `.geography-e004` ; la classe est posée sur `.geo-layout` avec `data-e004="1"`. Aucune règle de `styles.css` n'est surchargée hors du besoin. |
| **E004-02 — Rose textuelle** | `geography-e004-rose` dans `#c3b-map` : huit libellés `Nord, Nord-Est, Est, Sud-Est, Sud, Sud-Ouest, Ouest, Nord-Ouest` (`geography-e004-point-*`) plus un centre. Le cap sélectionné est marqué par `aria-current` **et** par une mise en évidence typographique (gras + soulignement), jamais par la couleur seule. |
| **E004-03 — Axe du nord géographique** | `geography-e004-axe` : trait vertical et libellé « Nord géographique · haut du cadre ». Une note `role="note"` précise que le jeu de données ne contient ni déclinaison ni nord magnétique, et qu'aucune valeur de ce type n'est affichée. |
| **E004-04 — Cap du lieu actif** | `parseViewBox()` lit les quatre nombres du `viewBox` ; `capFromScene()` lit le `cx`/`cy` du marqueur actif, calcule `atan2(dx, −dy)`, normalise en `[0, 360)` et choisit le secteur de 45° le plus proche. Si le marqueur manque ou si les nombres sont invalides, le texte dit « non calculable » au lieu d'affabuler. Recalcul synchrone sur `wheel`, `pointerup` et les touches de zoom. |
| **E004-05 — Sélecteur de cap** | `geography-e004-groupe` est un `radiogroup` de huit boutons (`geography-e004-dir-*`), `role="radio"` + `aria-checked` (choix unique, donc **pas** d'`aria-pressed`), roving tabindex, cibles tactiles ≥ 44 px, focus visible. |
| **E004-06 — Laboratoire canvas** | `geography-e004-canvas` : un seul canvas, huit rayons (cardinaux plus longs que les intercardinaux), lettres, cercle et aiguille. DPR plafonné à 2 (`Math.min(2, devicePixelRatio)`), une seule écriture par image, couleurs lues dans les variables de thème avec repli. `tabindex="0"`, `role="img"`, `aria-label` unique et `aria-describedby` vers les instructions clavier. |
| **E004-07 — Readout et légende** | `geography-e004-readout` est une région `role="status" aria-live="polite" aria-atomic="true"` qui annonce « Cap sélectionné : … (deg° …) ». La liste `geography-e004-legende` donne les huit noms **et** les huit angles (0°, 45°, …, 315°) en texte indexable. |
| **E004-08 — Mesures référencées** | `geography-e004-mesures` : 360° pour un tour, 8 points, `360 ÷ 8 = 45°` entre deux points consécutifs, un quart de tour = 90° = deux octants, axes Nord–Sud et Est–Ouest à angle droit. Trois grandeurs chiffrées dont une comparée à une référence (le quart de tour). |
| **E004-09 — Navigation clavier** | Un seul écouteur délégué sur `geography-e004-bloc` sert le radiogroupe **et** le canvas : ←/→ parcourent le cadran, ↑/↓ aussi, `Début` = Nord, `Fin` = Nord-Ouest, avec `preventDefault()` et `stopPropagation()` pour ne pas perturber le routeur global. Le texte `geography-e004-clavier` documente ces touches. |
| **E004-10 — Limite falsifiable et mouvement** | `geography-e004-limite` énonce l'angle mort et une vérification reproductible : zoomer/déplacer la carte peut changer le cap affiché alors que les coordonnées restent identiques ; un cap qui changerait sans changement du viewBox, ou un azimut réel annoncé, constituerait un défaut. Côté animation : **une seule** boucle rAF (`ensureLoop()` est l'unique appel à `requestAnimationFrame`), annulée sur `document.hidden` et reprise au retour d'onglet ; `ctx.reducedMotion()` est relu à chaque image et provoque l'arrêt immédiat de l'aiguille. |

## Contraintes vérifiées

- **Un seul fichier de code** : `E004.js` remplace le stub. Aucun autre fichier source, registre, index, feuille de style ou jeu de données n'est modifié.
- **Contrat d'enregistrement** : un seul `import { register } from './registry.js'` et un seul `register('E004', (ctx) => { … })`.
- **CSS** : injecté uniquement via `ctx.css('geography-e004', …)`, sélecteurs tous préfixés, media queries `max-width:620px` et `prefers-reduced-motion:reduce`.
- **Identifiants** : tous préfixés `geography-e004-*` ; les nœuds sont accrochés à `#c3b-map` ou à `.geo-panel`, jamais directement au stage ni au layout, pour rester hors de la portée du tiroir de diagnostic (`_diagnostics.js` masque les ids suivant `-eNN` dont le parent direct est le stage/layout).
- **Idempotence** : `ensureNode()` relit le DOM avant création, les écouteurs locaux sont protégés par `data-e004-cap` / `data-e004-keys`, l'écouteur `visibilitychange` est installé une seule fois au niveau module.
- **Zéro console / zéro réseau / zéro aléa** : aucune journalisation, aucun `fetch`, XHR, `src` distant, `@import`, `url(http…)`, aucune valeur pseudo-aléatoire. `node --check src/views/geography/E004.js` : **OK**.
- **Animation** : une boucle rAF au plus, suspension sur `document.hidden`, respect de `ctx.reducedMotion()`, un seul canvas dessiné par image, DPR ≤ 2, aucune autre source de `requestAnimationFrame`.
- **Accessibilité** : cibles ≥ 44 px, focus visible avec contour + halo, `aria-pressed` réservé aux bascules indépendantes (absent ici), `radiogroup`/`radio` pour le choix unique, canvas focalisable et pilotable au clavier, region live pour l'annonce, état sélectionné doublé par un texte et un style non chromatique.
- **Contenu lisible sans JS** : la vue de base reste intacte ; toutes les informations ajoutées sont des éléments `<p>`, `<li>`, `<h3>`, `<figcaption>` présents dans le DOM. Le canvas ne porte aucune information qui ne soit aussi écrite en texte (légende des huit angles et readout).
- **Français** : libellés, notes, annonces, messages d'erreur et commentaires en français.
