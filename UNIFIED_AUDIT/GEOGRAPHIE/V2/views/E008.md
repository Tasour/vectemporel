# E008 — Hémisphères nord/sud/est/ouest (vue GEOGRAPHIE, passe V2)

Lentille : E008. Module possédé : `src/views/geography/v2/E008.js` (remplace le
stub V2). Lectures seules : la passe 1 (`src/views/geography/E008.js` et
`UNIFIED_AUDIT/GEOGRAPHIE/views/E008.md`), `src/views/geography/v2/registry.js`,
`src/views/geography/v2/index.js`. Aucun fichier de la passe 1, aucun registre
et aucun index modifié.

**Thème.** Les quatre hémisphères définis par deux grands cercles : l'équateur
(0° de latitude) sépare le nord du sud, le méridien de Greenwich (0° de
longitude) et son antipode à 180° séparent l'est de l'ouest. La V2 fournit un
panneau pédagogique autonome et un laboratoire canvas qui ne projette que des
formules déterministes : aucun chiffre fabriqué, aucune coordonnée de projet
réinventée, aucune graine aléatoire.

**Contrat respecté.** `import { register } from './registry.js'` puis
`register('E008', (ctx) => { … })` avec
`ctx = { viewId, stage, layout, css, el, reducedMotion() }`. CSS unique via
`ctx.css('geography-v2-e008', …)`. Tous les identifiants DOM sont préfixés
`geography-v2-e008-` et le miroir d'état porte des attributs
`data-geography-v2-e008-*`, distincts de ceux de la passe 1 (`geography-e008-*`).
Zéro journalisation, zéro réseau, zéro graine aléatoire, une seule boucle
`requestAnimationFrame` avec pause sur `document.hidden` et respect de
`ctx.reducedMotion()`. Tout le texte pédagogique est du HTML sémantique présent
dans le DOM indépendamment de l'animation. Français partout.

## E008-01 — Définitions canoniques et contenu lisible sans animation

- **Problème.** La vue ne donne aucun repère explicite pour décider à quel
  hémisphère appartient un point ; un simple dessin de globe laisserait croire
  que la frontière est approximative.
- **Solution.** `buildFacts()` (trois paragraphes), `buildDefinitions()` (une
  liste de définitions de quatre paires) et `buildTables()` (deux tableaux avec
  `<caption>` et en-têtes `scope`) posent les frontières exactes (0° de latitude,
  0° et 180° de longitude) et les conséquences de l'obliquité (tropiques ≈ 23,44°,
  cercles polaires ≈ 66,56°, calculés depuis `90 − 23,44`).
- **Impact.** Le lecteur dispose de la définition avant même de manipuler le
  laboratoire ; le texte reste dans le DOM même si le canvas échoue ou si le
  mouvement réduit désactive l'animation.
- **Risque.** Un contenu uniquement généré par le canvas serait invisible aux
  moteurs d'indexation ; mitigé par le texte sémantique statique inséré avant le
  laboratoire.
- **Vérification.** `#geography-v2-e008-panel h2` existe ; trois paragraphes
  `.geography-v2-e008-fait` sont présents ; le `<dl>` contient quatre paires
  `<dt>/<dd>` ; le premier tableau a quatre lignes de données.

## E008-02 — Classification déterministe par le signe de lat/lon

- **Problème.** Sans règle explicite, les cas limites (point sur l'équateur ou
  sur le méridien de Greenwich) sont ambigus : « nord ou sud ? », « est ou
  ouest ? ».
- **Solution.** `hemisphereOf(lat, lon)` renvoie `{ns, ew}` en testant uniquement
  le signe : `lat > 0 → nord`, `lat < 0 → sud`, sinon `équateur` ; `lon > 0 → est`,
  `lon < 0 → ouest`, sinon `méridien`. `classifyPhrase()` convertit ce résultat en
  phrase lisible pour les cinq configurations, frontières comprises. Le marqueur
  canvas passe en cercle pointillé quand `cos(lat)·cos(lon) < 0` (face cachée).
- **Impact.** Un point exactement à (0°, 0°) est annoncé « au croisement de
  l'équateur et du méridien de Greenwich », jamais classé par défaut dans un camp.
- **Risque.** Un test de signe avec `>= 0` classerait à tort l'équateur dans le
  nord ; le code utilise strictement `> 0` et `< 0`.
- **Vérification.** `hemisphereOf(0, 0)` → `{ns:'équateur', ew:'méridien'}` ;
  `hemisphereOf(-33, -70)` → `{ns:'sud', ew:'ouest'}` ; `hemisphereOf(48, 2)` →
  `{ns:'nord', ew:'est'}`.

## E008-03 — Grandeurs chiffrées comparées à une référence

- **Problème.** Une carte des hémisphères reste abstraite sans mesure : un degré
  de longitude ne vaut pas la même distance à l'équateur et au 60e parallèle.
- **Solution.** `longitudeDegreeKm(lat) = 111,32 × cos(lat)` et le tableau des
  grandeurs donnent la référence explicite « 111,32 km à l'équateur ». Le
  `<p role="status">` (`#geography-v2-e008-readout`, `aria-live="polite"`)
  affiche la valeur courante, le nom d'hémisphère et l'écart à la référence.
  Les constantes (rayon, degré de grand cercle) sont des repères génériques.
- **Impact.** À 60° N/S, le degré de longitude passe à environ 55,7 km, soit la
  moitié de la référence équatoriale : l'effet est mesurable, pas seulement visuel.
- **Risque.** Une latitude hors bornes produirait un cosinus négatif ; `clamp`
  la ramène à [−90, 90] avant le calcul.
- **Vérification.** `longitudeDegreeKm(0) = 111,32` ;
  `longitudeDegreeKm(60) ≈ 55,66` ; le readout contient au moins trois nombres et
  la mention « référence 111,32 km à l'équateur ».

## E008-04 — Insolation : hauteur du soleil à midi

- **Problème.** Le lien entre latitude, saison et hémisphère reste implicite ; la
  déclinaison solaire n'est jamais montrée.
- **Solution.** Un curseur de déclinaison (δ entre −23,4° et +23,4°) alimente
  `solarNoonHeight(lat, δ) = max(0, 90 − |lat − δ|)`. Le readout compare la
  hauteur au point courant avec celle de l'équateur pour la même δ : référence
  explicite et formule réversible. Le `max(0, …)` borne physiquement l'absence
  de soleil au-dessus de l'horizon.
- **Impact.** À l'équinoxe (δ = 0), un point à 48° N voit le soleil à 42° ; au
  solstice de juin (δ ≈ +23,44°), la même formule donne ≈ 65,4°, sans table
  mémorisée.
- **Risque.** Une déclinaison hors de l'intervalle solaire donnerait une hauteur
  impossible ; le curseur et le clamp d'état bornent δ à ±23,4°.
- **Vérification.** `solarNoonHeight(48, 0) = 42` ; `solarNoonHeight(0, 0) = 90` ;
  le curseur δ a `min="-23.4"`, `max="23.4"` et le readout met la valeur courante
  en `<strong>`.

## E008-05 — Laboratoire : graticule et axes de séparation

- **Problème.** Un disque sans axes ne permet pas de lire « où passe la
  frontière » ; la couleur seule est illisible pour certains lecteurs.
- **Solution.** `drawLab()` trace le globe en projection orthographique centrée
  sur (0°, 0°) : parallèles et méridiens en traits fins, équateur en tiret long,
  méridien de Greenwich en pointillé, étiquettes N/S/E/O hors du disque. Le choix
  d'hémisphère est indiqué par des hachures (forme), jamais par une teinte seule ;
  la légende nomme chaque style de trait. Le DPR est plafonné à 2.
- **Impact.** Deux personnes avec des daltonismes différents distinguent les
  axes par la forme du trait et par le texte de la légende.
- **Risque.** Une graine aléatoire dans le dessin rendrait la figure
  irreproductible ; toutes les coordonnées sont des fonctions pures de l'état
  (`px(lat, lon)`) et du temps de balayage.
- **Vérification.** Le canvas porte `role="img"`, un `aria-label` unique et
  `aria-describedby` pointant vers `#geography-v2-e008-legend` ; aucun appel
  réseau dans `drawLab()` ; aucune graine aléatoire dans le module.

## E008-06 — Sélecteur d'hémisphère en radiogroupe

- **Problème.** Quatre hémisphères exclusifs ne doivent pas être traités comme
  quatre bascules indépendantes : `aria-pressed` sur chaque bouton laisserait
  croire qu'on peut tous les activer.
- **Solution.** Un `<fieldset role="radiogroup">` légendé contient quatre
  `<input type="radio">` de même `name` (`geography-v2-e008-hemi`) ;
  `syncControls()` remet à jour les quatre `checked`. Le hachurage du canvas suit
  le radio choisi (`ORDER` = nord, est, sud, ouest). L'`aria-pressed` reste réservé
  au seul bouton d'animation.
- **Impact.** Un seul hémisphère mis en évidence à la fois, annoncé comme choix
  unique par les lecteurs d'écran.
- **Risque.** Un `name` identique à celui de la passe 1 croiserait les deux jeux
  de radios ; le préfixe V2 isolent le groupe.
- **Vérification.** `document.querySelectorAll('input[name="geography-v2-e008-hemi"]:checked').length === 1` ;
  zéro `aria-pressed` sur les radios ; `data-geography-v2-e008-hemisphere` suit le
  choix.

## E008-07 — Curseurs latitude, longitude, déclinaison

- **Problème.** Sans contrôle de position, le marqueur et les mesures seraient
  figés : la lentille n'enseignerait qu'une seule configuration.
- **Solution.** Trois `<input type="range">` (φ −90…90, λ −180…180, δ −23,4…23,4)
  portent chacun un `aria-label` et un `aria-valuetext` mis à jour dans
  `syncControls()`, ainsi qu'un `<span>` de valeur (`geography-v2-e008-value`).
  Les bornes sont reclampées côté état pour résister à une valeur hors intervalle.
  Un bouton « Réinitialiser » ramène à (48° N, 2° E, δ = 0).
- **Impact.** L'apprenant peut traverser l'équateur et le méridien de Greenwich et
  voir la classification basculer en direct, puis revenir à un état de référence.
- **Risque.** Un `min`/`max` manquant laisserait le navigateur choisir une plage
  par défaut incompatible avec les formules ; les trois attributs sont explicites.
- **Vérification.** Les trois curseurs ont `min`/`max`/`step` explicites ; leurs
  `<label for>` pointent vers des ids existants ; le readout se met à jour à
  chaque événement `input`.

## E008-08 — Animation unique, pause et mouvement réduit

- **Problème.** Une boucle d'animation sans garde continue de dessiner dans un
  onglet masqué et ignore `prefers-reduced-motion`.
- **Solution.** Une seule variable `S.rafId` et une seule fonction `tick()`
  schedulent au plus une frame. `startLoop()` refuse de démarrer si
  `document.hidden`, l'événement `visibilitychange` appelle `stopLoop()`, et
  `tick()` désactive l'avancement de `S.sweep` quand `prefersReduced()` (qui
  interroge d'abord `ctx.reducedMotion()`) est active. Le méridien balayé est une
  fonction déterministe du temps écoulé (`−180 + sweep·360`) : aucune graine
  aléatoire, une seule boucle pour toute la lentille.
- **Impact.** Zéro dessin en arrière-plan, aucun mouvement imposé, consommation
  maîtrisée.
- **Risque.** Un second `requestAnimationFrame` provenant d'un autre greffon
  échapperait à la garde ; la lentille n'en installe qu'un seul et le libère à la
  masquerade de l'onglet.
- **Vérification.** Un seul `rafId` et un seul appel de schedule dans `tick()` ;
  masquer l'onglet met `data-geography-v2-e008-playing` à `0` et libère la frame ;
  avec mouvement réduit, `S.sweep` reste à sa valeur et le bouton bascule l'état
  sans animation.

## E008-09 — Équivalence clavier du laboratoire

- **Problème.** Un canvas non focalisable est invisible au clavier : ni le
  changement d'hémisphère ni la traverse de l'équateur ne sont atteignables sans
  souris.
- **Solution.** `tabindex="0"`, `role="img"`, un `aria-label` décrivant le
  comportement, `aria-describedby` vers la légende, et un gestionnaire `keydown` :
  ←/→ parcourent `['nord','est','sud','ouest']`, ↑/↓ déplacent la latitude par pas
  de 5°, `Home` (et `Origin` sur les navigateurs qui l'émettent) ramènent à
  (0°, 0°) en nord. Chaque touche consommée appelle `preventDefault()` puis
  `syncControls()`.
- **Impact.** Le laboratoire est entièrement pilotable au clavier, avec un nom
  accessible qui annonce les touches et une limite haute de latitude respectée.
- **Risque.** Une touche non gérée empêcherait la navigation normale si elle était
  consommée à tort ; le gestionnaire ne marque `used` que pour les touches
  effectivement traitées.
- **Vérification.** Tabuler jusqu'au canvas puis ← : le radio « Est » devient
  coché et `data-geography-v2-e008-hemisphere = "est"` ; ↑ depuis 48° donne 53°.
  Les boutons mesurent au moins 44 px et `:focus-visible` est visible.

## E008-10 — Miroir idempotent, CSS borné, zéro effet de bord

- **Problème.** `runEnhancements()` rejoue le greffon à chaque rendu : un état
  seulement dans une variable locale disparaîtrait, et une feuille de style
  réinjectée à chaque fois grossirait le `<head>`.
- **Solution.** `ctx.css('geography-v2-e008', …)` injecte une seule feuille
  portant cet id ; `ensurePanel()` réutilise le panneau existant s'il est connecté
  (aucun doublon d'écouteurs, gardé par `S.nodes.fresh`) ; `syncControls()` écrit
  un miroir `data-geography-v2-e008-*` (hémisphère, lat, lon, déclinaison, état de
  lecture, sweep, mouvement réduit). Les contrôles mesurent au moins 36 px
  (boutons 44 px) et le `:focus-visible` est visible. Le badge de la carte
  (`#geography-v2-e008-badge`) est posé sans modifier le SVG existant.
- **Impact.** État observable par un test ou une relecture, aucune fuite entre
  rendus, aucune collision avec la passe 1 ou avec E001 (préfixes et ids
  distincts).
- **Risque.** Une réinjection de CSS ou un second panneau dupliquerait les ids et
  les écouteurs ; `ctx.css` est idempotent par id et `ensurePanel` est guidé par
  `isConnected`.
- **Vérification.** Trois rendus successifs → miroir identique et un seul nœud
  `#geography-v2-e008-panel` ; aucune occurrence de journalisation, d'appel réseau
  ou de graine aléatoire dans le module ; `node --check
  src/views/geography/v2/E008.js` : PASS.

## Blocages / délimitations

- Aucun bloquant fonctionnel.
- La projection du laboratoire est orthographique centrée sur (0°, 0°) : le
  marqueur d'un point de longitude supérieure à 90° en valeur absolue est signalé
  « face cachée » plutôt que déplacé fictivement.
- Les badges de passe 1 et V2 coexistent sur la même carte avec des ids distincts
  (`geography-e008-badge` / `geography-v2-e008-badge`) ; aucun SVG n'est modifié.
- Les constantes (rayon moyen, degré de grand cercle 111,32 km, obliquité
  23,44°) sont des repères géographiques génériques, pas des coordonnées du
  dataset local.
