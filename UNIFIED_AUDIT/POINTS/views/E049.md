- **Preuve** : `E049.js:161-165` donne un id au `.points-title` existant via `ensureId` (`:100-107`, qui réutilise un id antérieur), puis pose `role="region"` et `aria-labelledby` sur `.points-matrix` uniquement s'ils manquent. - **Solution** : la `<section class="points-matrix">` devient un repère (landmark) nommé par son propre titre « N points isolés », sans ajouter de contenu ni modifier le titre. `points.js:30-32` produit le titre ; E049 se contente de le relier.
- **Impact** : un lecteur d'écran peut sauter directement à la matrice et entendre son nom ; la structure sémantique de `points.js` reste intacte pour les autres lentilles.
- **Effort** : S
- **Vérification** : relecture — `role` et `aria-labelledby` absents avant passage, présents après, id du titre non écrasé si E002/E004/E018 l'ont déjà nommé ; `.points-matrix` n'a pas d'id `points-e049-*`.

## Blocages / limites inter-domaines

- `aria-describedby` de la grille est enrichi par append (`:116-125`) : l'ordre d'apparition des annotations dépend de l'ordre d'enregistrement des lentilles (`index.js` importe E001…E100). Le texte de E049 est présent, mais sa position relative à ceux de E002/E004 n'est pas garantie.
- Le contexte `points` n'expose pas `say()` : E049 n'ajoute aucune région live et ne double pas celles de E013/E035. Une annonce vocale des changements d'ère/de filtre reste hors du contrat de cette lentille.
- `ensureId` réutilise un id déjà posé par E002/E004/E018 plutôt que de le remplacer : si une lentille antérieure renomme un id, l'ARIA de E049 suit l'id présent. Aucun id n'est figé artificiellement.
- La neutralisation sous mouvement réduit emploie `!important` sur `.points-grid *` : elle écrase volontairement les transitions des autres lentilles dans ce périmètre (dont E001), au nom de l'accessibilité, sans modifier leur CSS source.
- La note de lecture n'est créée que si `.points-matrix` existe (`:193`) : avec un ctx minimal sans matrice, le greffon reste silencieux plutôt que d'appendre un id sous `layout` (qui serait masqué par `_diagnostics.js`).
- `.points-families` n'est pas attaché au DOM par `points.js:108-109` (le `<div>` local n'est jamais appendu) : E049 ne répare pas ce défaut, la vue étant un fichier non possédé.
