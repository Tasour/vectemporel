# Atlas des lieux

> Généré par `npm run build:places`. 2026-11-17.

114/120 lieux localisés à partir de l’API Wikipedia (fr puis en). Les autres
conservent leur fiche descriptive mais n’ont pas de point sur la carte : aucune
coordonnée n’est inventée.
